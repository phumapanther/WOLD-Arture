# ไอเทมที่ยังไม่มีรูป — **2 จาก 158 ชิ้น** (ตรวจสด 2026-09-24)

รายการนี้ **ดึงจากแคตตาล็อกจริงในเพลส** ไม่ได้ไล่อ่านไฟล์ด้วยตา (`icon = ""` คือเครื่องหมายว่ายังไม่มีรูป)

## วิธีใส่รูป

1. อัปโหลดรูปเข้า Roblox (Creator Dashboard → Decals) แล้วก๊อป **image id** มา
   · ⚠️ **ต้องเป็น image id ไม่ใช่ decal id** — วิธี resolve ที่ถูกคือ `InsertService:LoadAsset(decalId)`
   แล้วอ่าน `Texture` ของ Decal ที่ได้ (**ห้ามใช้ `insert_asset` แล้วอ่าน Texture** มันคืนเลขเดิมที่ส่งไป)
2. วางที่ช่อง `icon` ของชิ้นนั้นใน `src/ReplicatedStorage/ItemCatalog.lua`
3. **จบแค่นั้น** — ⌛ ที่ขึ้นแทนอยู่ตอนนี้หายไปเอง ไม่ต้องแก้ที่อื่นเลย (`UI/ItemIcon.lua` แขวน ⌛
   ให้ทุกช่องที่ไม่มีรูป และถอดออกเองเมื่อมีรูป · ต่อสายไว้ 13 หน้าต่างแล้ว)

## ที่เหลือ

ผู้ใช้อัปโหลดรูปของเกาะฟาร์มมิ่งมาครบ 37 ชิ้นเมื่อ 2026-09-24 เหลืออีกสองชิ้น

| id | ชื่อ | หมายเหตุ |
|---|---|---|
| `Chest_Magic` | หีบเวทมนตร์ | ของเกมหลัก — รางวัลที่หนึ่งของแมตช์ PVP และขั้น 30 ของแบทเทิลพาส |
| `Deco_Stump` | ตอไม้ | ของตกแต่งบนเกาะ — ไม่ได้อยู่ในชุดที่ส่งมา |

## ข้อควรระวัง

- **`Deco_Crate` (ลังไม้) กับ `Deco_FlowerPot` (กระถางดอกไม้) ใช้รูปเดียวกัน**
  เพราะรายการที่ส่งมาให้ decal เลขเดียวกันทั้งสองตัว (`104678721654072`) น่าจะคัดลอกผิดตัว
  อัปรูปลังไม้จริงแล้วเอา image id มาใส่ทับ `Deco_Crate` ได้เลย
- **สายแร่เจ็ดชนิดยืมรูปจากไอเทมแร่โดยตั้งใจ** (`Wild_Coal` ↔ `Coal` ฯลฯ) ตามที่สั่งไว้ 2026-09-23
  คัดลอกด้วยลูปท้ายตาราง `ItemCatalog.Items` — เปลี่ยนไอคอนแร่แล้วสายแร่ตามไปเอง

## บันทึกจากรอบ 2026-09-24

เลขทั้ง 37 ตัวที่ผู้ใช้ส่งมาเป็น **decal id ทั้งหมด** ไม่มีสักตัวที่เป็น image id
ถ้าใส่ตรงๆ จะไม่ขึ้นรูปสักอัน — แต่ก็ไม่ขึ้น ⌛ ด้วย เพราะช่อง `icon` ไม่ว่าง
จึงเห็นเป็นช่องเปล่าๆ ที่อธิบายยากกว่า ⌛ เสียอีก — **ต้อง resolve ก่อนเสมอ**
