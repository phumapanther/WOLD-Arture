รายการนี้ **ดึงจากแคตตาล็อกจริง** ไม่ได้ไล่อ่านไฟล์ด้วยตา (`icon = ""` คือเครื่องหมายว่ายังไม่มีรูป)
· รอบนี้ประเมิน `ItemCatalog` ตัวจริงแบบออฟไลน์ด้วย Luau CLI (`~/tools/luau/luau.exe` + ตัวแทน Roblox API) — ไม่ต้องเปิด Studio

## วิธีใส่รูป

1. อัปโหลดรูปเข้า Roblox (Creator Dashboard → Decals) แล้วก๊อป **image id** มา
   · ⚠️ **ต้องเป็น image id ไม่ใช่ decal id** — วิธี resolve ที่ถูกคือ `InsertService:LoadAsset(decalId)`
   แล้วอ่าน `Texture` ของ Decal ที่ได้ (**ห้ามใช้ `insert_asset` แล้วอ่าน Texture** มันคืนเลขเดิมที่ส่งไป)
2. วางที่ช่อง `icon` ของชิ้นนั้นใน `src/ReplicatedStorage/ItemCatalog.lua`
3. **จบแค่นั้น** — ⌛ ที่ขึ้นแทนอยู่ตอนนี้หายไปเอง ไม่ต้องแก้ที่อื่นเลย (`UI/ItemIcon.lua` แขวน ⌛
   ให้ทุกช่องที่ไม่มีรูป และถอดออกเองเมื่อมีรูป · ต่อสายไว้ 13 หน้าต่างแล้ว)

## ตรวจด้วยตาแล้วทั้ง 37 รูป (2026-09-24)

**วิธี: แปะ decal บนแผ่นเรียงเป็นตารางใน Edit แล้ว `screen_capture`** — เร็วกว่าเปิดทีละรูปมาก
- ⚠️ **กล้องที่มองไปทาง +Z จะกลับซ้ายขวา** (world +X ไปอยู่ซ้ายจอ) อ่านตารางจากภาพแบบนั้นไม่ได้
  — ให้หันหน้าแผ่นไป +Z (`Decal.Face = Back`) แล้วเอากล้องไปยืนฝั่ง +Z มองกลับมา
- ⚠️ **`BillboardGui` ไม่ขึ้นใน `screen_capture`** ใช้ `SurfaceGui` บนแผ่นแยกใต้รูปแทน
- ที่เจอ: รูปที่ส่งมาเป็น "รั้ว" ที่แท้จริงเป็น **ตอไม้** · รูป "กระถาง" ที่แท้จริงเป็น **ลังไม้**
  อีกสองตัวที่ต้องรอรูปจริงคือ **แผ่นทางเดิน** (ตอนนี้เป็นหินเกลี้ยงซ้ำกับก้อนหิน) กับ **กระถาง**
