# ไอเทมที่ยังไม่มีรูป — 39 จาก 158 ชิ้น (ตรวจสด 2026-09-23)

รายการนี้ **ดึงจากแคตตาล็อกจริงในเพลส** ไม่ได้ไล่อ่านไฟล์ด้วยตา (`icon = ""` คือเครื่องหมายว่ายังไม่มีรูป)

## วิธีใส่รูป

1. อัปโหลดรูปเข้า Roblox (Creator Dashboard → Decals) แล้วก๊อป **image id** มา
   · ⚠️ **ต้องเป็น image id ไม่ใช่ decal id** — วิธี resolve ที่ถูกคือ `InsertService:LoadAsset(decalId)`
   แล้วอ่าน `Texture` ของ Decal ที่ได้ (**ห้ามใช้ `insert_asset` แล้วอ่าน Texture** มันคืนเลขเดิมที่ส่งไป)
2. วางที่ช่อง `icon` ของชิ้นนั้นใน `src/ReplicatedStorage/ItemCatalog.lua`
3. **จบแค่นั้น** — ⌛ ที่ขึ้นแทนอยู่ตอนนี้หายไปเอง ไม่ต้องแก้ที่อื่นเลย (`UI/ItemIcon.lua` แขวน ⌛
   ให้ทุกช่องที่ไม่มีรูป และถอดออกเองเมื่อมีรูป · ต่อสายไว้ 13 หน้าต่างแล้ว)

## ทำอันไหนก่อนดี

เรียงตามความถี่ที่คนเห็น ไม่ใช่ตามราคา:

1. **`Chest_Magic`** — ชิ้นเดียวที่อยู่ในเกมหลัก และเป็นรางวัลใหญ่สุดของ PVP
2. **เมล็ดพันธุ์** — ของชิ้นเดียวที่ผู้เล่นซื้อซ้ำทุกวันตลอดเกม
3. **ของป่า 4 ชิ้น** — ต้นโอ๊ก/ต้นสน/พุ่ม/หิน หน้าตาต่างกันชัดแต่ ⌛ เหมือนกันหมด แยกไม่ออก
   (สายแร่เจ็ดชนิดยืมรูปไอเทมแร่ไปแล้ว ไม่ต้องทำ)
4. **ของตกแต่งชิ้นเล็ก 15 ชิ้น** — ซื้อทีละหลายชิ้น อยู่ในหน้าร้านตลอด
5. ที่เหลือ (บ้าน · เฟอร์นิเจอร์ · โครงสร้างฟาร์ม · สัตว์เลี้ยง) ซื้อครั้งเดียวจบ รอได้
