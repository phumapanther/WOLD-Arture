# สนาม PVP 3v3 — สิ่งที่สร้างแล้ว (2026-09-23)

ความต้องการอยู่ใน `05-future-modes.md` §2 · โครงเพลสอยู่ใน `06-modes-build-plan.md` §4 ·
หน้าปาร์ตี้ในล็อบบี้อยู่ใน `07-pvp-lobby-ui.md` — **ไฟล์นี้บอกว่าโค้ดที่เขียนไปแล้วทำงานยังไง**

> ⚠️ **ยังไม่เคยรันในเพลสสนามจริง** เพราะเพลส `WOLD Arena` ยังไม่ถูกสร้าง — `ServerConfig.ArenaPlaceId`
> ยังเป็น `0` · ทุกอย่างข้างล่างเขียนครบและตรวจไวยากรณ์ผ่าน แต่การเล่นจริงยังไม่เคยเกิดขึ้น

## 1. เส้นทางของผู้เล่นหนึ่งคน

```
ล็อบบี้ (เพลสหลัก)                              สนาม (เพลส WOLD Arena, เซิร์ฟที่ถูกจอง)
─────────────────                               ──────────────────────────────────────
แท็บ PVP → ตั้งปาร์ตี้ ≤3 คน
   PvpPartyGui / LobbyParty.server
กด [เล่น] → เข้าคิว
   ArenaQueue.Join
   ├── ครบ 6 คน            → ไปเลย
   └── ครบ 3 นาที          → เติมบอทให้ครบ แล้วไป
ArenaRegistry.CreateMatch                  →   ServerConfig.ArenaMatch (อ่านจาก DataStore ตอนบูต)
   จองเซิร์ฟ + เขียน arenamatch_<id>            ArenaMatch.server รับช่วงต่อ
TeleportToPrivateServer                    →   รอบที่ 1 … ชนะ 3 รอบก่อน = จบ
                                               ArenaRewards ฝากรางวัลไว้
   PvpRewards.server (เพลสหลัก)            ←   กลับล็อบบี้ → เข้าเกมหลัก → ได้เงิน+หีบ
```

**ทีมไม่ได้มาจาก TeleportData** เซิร์ฟแมตช์อ่านจาก DataStore ด้วย `PrivateServerId` ของตัวเอง
(`06-modes-build-plan.md` §4.2 สั่งไว้) — ใครเทเลพอร์ตเข้าเซิร์ฟที่ไม่ใช่ของตัวเองจะถูกส่งกลับล็อบบี้

## 3. กติกาที่ต่างจากเกมหลัก และ "สวิตช์" ที่ทำให้ต่าง

ทุกข้อเป็นธงที่ **เซิร์ฟแมตช์เท่านั้น** เป็นคนเปิด เพลสหลักไม่เคยรันบรรทัดที่เปิดมัน

| เรื่อง | สวิตช์ | ผล |
|---|---|---|
| ตายแล้วออกยาว | `Vitals.NoDownedMode = true` | เลือดหมด = ตายทันที ไม่มีท่าคลาน ไม่มีใครมาอุ้ม |
| เกิดตามรอบ | `Players.CharacterAutoLoads = false` | แมตช์เป็นคนตัดสินว่าใครเกิดเมื่อไหร่ |
| ปืน/ธนู | `ArenaConfig.CombatOverrides` | ปืน 34 ดาเมจ ไม่ล้มคน · ธนู 30 ไม่ล้มคน |
| ตีกันเองไม่ได้ | `ArenaAccess.Friendly` | ทีมของแมตช์ (ตี้ของล็อบบี้ไม่ได้เดินทางข้ามเพลส) |
| ฮีลหมู่ | `ArenaAccess.Friendly` ใน `WeaponSkills` | คทาฮีลเฉพาะทีมตัวเอง (ในเมืองยังฮีลทุกคนเหมือนเดิม) |
| สกิลโดนบอท | `alsoHitBots` ใน `WeaponSkills` | สกิล Q ในเกมหลักไม่เคยโดนมอน ในสนามต้องโดน |
| กระเป๋าเปล่า | สาขา `IsArena` ใน `PlayerInventory` | ไม่รอโปรไฟล์ ไม่มีของเปิดตัว ไม่เซฟอะไรกลับ |
| กระเป๋าใช้ไม่ได้ | `ArenaMode` ใน `InventoryController` | ปุ่ม B เป็นของร้านแทน · F เป็น "ใช้ยา" แทนฟาร์มออโต้ |

## 4. หนึ่งรอบหน้าตาเป็นยังไง

```
buy  35 วิ (รอบแรก) / 25 วิ   ร้านเปิดเอง · ทุกคนถูก Anchor ไว้ที่ฐาน
live สูงสุด 150 วิ            ฆ่าอีกฝั่งให้หมด · หมดเวลา = ตัดสินด้วยคนที่ยังยืน แล้วดูเลือดรวม
roundEnd 7 วิ                 จ่ายซิลเวอร์ · ขึ้นป้ายว่าใครชนะรอบ
→ ชนะครบ 3 รอบ (หรือครบ 9 รอบ) → matchEnd 25 วิ → ตารางอันดับ → กลับล็อบบี้
```

**ซิลเวอร์**: เริ่ม 800 · ชนะรอบ +1500 · แพ้รอบ +900 · ต่อคิล +250 · คนฆ่าเยอะสุดของรอบ +300
· สะสมข้ามรอบ เพดาน 9000 · **ไม่ใช่ไอเทม `Silver` ในกระเป๋า** และเอาออกจากสนามไม่ได้

**ของที่ซื้อ**: อาวุธ 1 / เกราะ 1 / ของใช้ 1 ต่อรอบ · ซื้อแล้วสวมให้เลย · ซื้อชิ้นใหม่ = ทับของเก่าทิ้ง
· อาวุธกับเกราะอยู่ข้ามรอบ · ยาหมดทุกจบรอบ · ปืนมากับกระสุน 16 นัด ยิงหมดต้องซื้อใหม่

## 5. แมพ

`mapgen/100_arena_maps.lua` สร้างสองด่าน: **โรงหล่อ** (Foundry) และ **บ่อพักน้ำ** (Cistern)
แมตช์สุ่มเลือกตอนจองเซิร์ฟ · ทั้งสองแมพอยู่ในเพลสพร้อมกัน ห่างกัน 4,000 สตัด

- **สมมาตรจริงโดยโครงสร้าง**: เขียนครึ่งเดียวแล้วหมุน 180° รอบแกนกลาง — ระยะจากสปอว์นถึงกลางแมพ
  ของสองฝั่งเท่ากัน 100% โดยไม่ต้องไปวัด
- **สามเลน** (ซ้าย/กลาง/ขวา) จากกำแพงแบ่งเลนสองแผง เปิดช่องข้ามเลนที่ปลายทั้งสองข้าง
- **จุดปะทะสองจุด** ยกพื้นเตี้ย + ลัง + เสา · ของบังกลางเลนกลาง กันการยืนยิงข้ามแมพจากจุดเกิด

**ยังไม่มีแมพในเพลส = ยังเล่นได้**: `ArenaMatch` ปูสนามชั่วคราว (พื้น + กล่องบัง 5 ใบ + แท่นเกิด)
ให้รอบเดินได้ พร้อมคำเตือนในล็อก — มันมีไว้ให้เทสระบบ ไม่ใช่แมพจริง

## 6. บอท

- เติมเมื่อ **ค้นหาห้องครบ 3 นาทีแล้วยังไม่ครบ 6 คน** หรือเมื่อแอดมินกด "เริ่มเลย"
- ร่างมาจาก `ServerStorage.WOLD_ArenaBots` ถ้ามี ไม่มีก็ `CreateHumanoidModelFromDescription`
- **ถูกตีด้วยทางเดียวกับมอนในเกมหลัก** (แท็ก `WOLD_Mob` + `MobAccess.Damage`) ระบบต่อสู้จึงไม่ต้องแก้เลย
- AI: เดินหาศัตรูที่ใกล้ที่สุดในรัศมี 140 · ฟันทุก 1.1 วิ ดาเมจ 12 · ไม่เห็นใครก็เดินเข้ากลางแมพ
- **ยังไม่มีท่าเดิน** ถ้าใช้ร่างสำรอง (ไม่มีสคริปต์ Animate ของ Roblox) — ต้องอบร่างต้นแบบเข้าเพลสก่อน

บั๊กที่เจอระหว่างทาง (แก้แล้ว):
- ⚠️ `Inventory.RemoveById` เป็น **ทั้งหมดหรือไม่เอาเลย** — โค้ดเดิมสั่ง `RemoveById(..., 99)` เพื่อ "ลบทั้งหมด"
  ซึ่งไม่ลบอะไรเลยเมื่อมีน้อยกว่า 99 → ยาเก่า/กระสุนเก่าค้างกระเป๋า · ใช้ `removeAll` (นับก่อนแล้วลบเท่าที่มี)
- ⚠️ ซื้ออาวุธชิ้นใหม่ทับ: ลบของเก่า *ก่อน* สวม แต่ `Inventory.Equip` คืนชิ้นที่ถอดลงกระเป๋า → อาวุธเก่าเด้งกลับมากอง
  · ตอนนี้ลบ **หลัง** สวม
- ⚠️ `PlayerJoin.Each` เรียก `spawnPlayer(f, ...)` โดยไม่เคยประกาศ `f` → คนเข้าช่วง warmup/buy error ทุกคน
