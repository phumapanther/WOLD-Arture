# หน้าล็อบบี้ของโหมด PVP — สเปกจากภาพที่ผู้ใช้ส่ง (2026-09-23)

ผู้ใช้ส่งภาพร่างมาห้าหน้าจอ **ยังไม่ได้เริ่มเขียนโค้ด** — เอกสารนี้คือสิ่งที่อ่านได้จากภาพ
เพื่อไม่ให้ดีไซน์หายไปกับประวัติแชท

> ⚠️ **เพลส Arena ยังไม่มีอยู่จริง** (`ACTIVE_MODES.PVP` ยังเป็น false · ดู `06-modes-build-plan.md`)
> ปุ่ม "เล่น" จึงยังไม่มีปลายทางให้เทเลพอร์ตไป — หน้าจอนี้สร้างและเทสได้ก่อน แต่จบวงจรไม่ได้

## โครงหน้าจอ

แท็บ PVP อยู่ในแถบเดียวกับ Roleplay/Farming ที่มีอยู่แล้ว (`UI/ChannelSelectGui.lua`)
เนื้อหาข้างในเป็น **หน้าปาร์ตี้** ไม่ใช่รายการเซิร์ฟเวอร์แบบแท็บอื่น

```
┌─────────────────────────────────────────────────────────┐
│ ปาร์ตี้                                                  │
│                                                         │
│    ┌────────┐    ┌────────┐    ┌────────┐              │
│    │ อวตาร  │    │        │    │        │              │
│    │        │    │   ✚    │    │   ✚    │              │
│    │ ชื่อฉัน │    │        │    │        │              │
│    └────────┘    └────────┘    └────────┘              │
│                                                         │
│                    ( เล่น )                             │
└─────────────────────────────────────────────────────────┘
```

- **สามช่อง** = ปาร์ตี้ 3 คนตามดีไซน์ PVP 3v3 เดิม (ระบบตี้ในเกมตั้ง `SocialConfig.PartyMax = 4`
  ซึ่งเป็นคนละตัวเลข — ต้องตัดสินว่าจะใช้ตัวไหนก่อนเขียน)
- ช่องแรกเป็นเราเสมอ: รูปอวตารเต็มตัว + ชื่อผู้เล่นข้างล่าง
- ช่องว่างเป็นปุ่ม **✚** กดแล้วเปิดรายชื่อเพื่อน
- ปุ่ม **เล่น** สีเขียวอยู่กลางด้านล่าง กดแล้วเข้าคิวจับคู่

## ห้าสถานะที่ภาพครอบคลุม

| # | สถานะ | สิ่งที่เห็น |
|---|---|---|
| 1 | ปาร์ตี้ว่าง | ช่องเรา + ช่องว่างสองช่องมีเครื่องหมาย ✚ · ปุ่ม "เล่น" |
| 2 | ได้รับคำเชิญ | กล่องเล็กลอยเหนือช่องที่สอง "คุณ ... ชวนเข้าปาตี้" + ปุ่ม **ตกลง** (เขียว) / **ยกเลิก** (แดง) |
| 3 | มีเพื่อนแล้ว | ช่องที่สองกลายเป็นอวตาร + ชื่อเพื่อน · ช่องที่สามยังเป็น ✚ |
| 4 | รายชื่อเพื่อน | แผงทึบซ้อนทับกลางจอ หัวข้อ "รายชื่อเพื่อน" · แต่ละแถวมีชื่อกับปุ่ม **ชวน** (เขียว) |
| 5 | กำลังจับคู่ | ข้อความ "กำลังค้นหาห้อง 1.30 นาที" (นาฬิกาเดินขึ้น) แทนปุ่มเล่น · ปุ่ม **ยกเลิก** (แดง) |

## สิ่งที่มีอยู่แล้วและใช้ซ้ำได้

- **ระบบตี้ในเกม** `Party.lua` + `PlayerParty.server.lua` — แต่ตี้นั้นอยู่ใน**เซิร์ฟเกม** ส่วนอันนี้
  ต้องเกิดใน **ล็อบบี้** ซึ่งเป็นคนละเซิร์ฟและ**ไม่เปิดเซสชันโปรไฟล์** (กฎเดิม) จึงใช้โค้ดเดิมตรงๆ ไม่ได้
  ต้องมีตี้ของล็อบบี้แยก หรือย้าย `Party` ให้ทำงานได้ทั้งสองที่
- **รายชื่อเพื่อน** อ่านได้จาก `ProfileAccess.PeekAsync(userId).Social.Friends` (ทางเดียวกับที่
  `LobbyServer` ใช้ตัดสินสิทธิ์เข้าเกาะเพื่อนแล้ว)
- **รูปอวตาร** `Players:GetUserThumbnailAsync` — `ChannelSelectGui` วาดรูปผู้เล่นในแถวช่องอยู่แล้ว
- **หน้าต่างยืนยัน** `ClassActionGui:AskConsent` มีทรงเดียวกับภาพที่ 2 (ตกลง/ยกเลิก)

## ที่ยังต้องตัดสินก่อนเขียน

1. ปาร์ตี้ 3 หรือ 4 คน (ภาพวาด 3 · `SocialConfig.PartyMax` = 4)
2. คำเชิญข้ามเซิร์ฟหรือเฉพาะคนที่อยู่ในล็อบบี้ด้วยกัน (ข้ามเซิร์ฟต้องใช้ MessagingService)
3. จับคู่จริงหรือให้แอดมินเริ่มแมตช์เองก่อน — `06-modes-build-plan.md` เขียนไว้ว่า
   **แอดมินเริ่มแมตช์คนเดียวได้ต้องมาก่อนระบบจับคู่** เพราะเป็นสิ่งเดียวที่ทำให้เทสสนามได้โดยไม่ต้องหาหกคน
