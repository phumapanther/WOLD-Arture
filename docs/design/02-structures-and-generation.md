# ส่วนที่ 3: เมืองหลวง Brasshaven

## โครงเมือง

แม่น้ำสายหลักลอดกำแพงเหนือที่ (0.055, 0.09) ไหลลงใต้แล้วเลี้ยวตะวันออกเฉียงใต้ลงอ่าวที่ (0.40, 0.40) แบ่งเมืองเป็น 2 ฝั่ง

- **ฝั่งตะวันออกเฉียงเหนือ (ที่สูง)** Crown Hill สูง 200 studs เหนือที่ราบ มี Ironcrest Keep บนยอด ลาดลงมาเป็น Crown Plaza เขตราชการ และเขตที่พักเหนือ
- **ฝั่งตะวันตกเฉียงใต้ (ที่ราบริมอ่าว)** จัตุรัสตลาด เขตที่พักหลัก ท่าเรือ โรงงาน ท่าเรือเหาะ

กำแพงเป็นรูปหลายเหลี่ยม 7 จุด (ดู `capital.wall.polygon`) กว้างประมาณ 3,400 × 4,000 studs ด้านอ่าว (0.44, 0.30) ถึง (0.30, 0.55) เป็นกำแพงกันคลื่นที่แนวน้ำพร้อมหอท่าเรือ 2 หอ และช่องเปิดปากท่า

- กำแพงสูง 30 หนา 8 หอคอยทรงกระบอกทุก 250 studs (รัศมี 14 สูง 45) ทางเดินบนกำแพง

# ส่วนที่ 5: สถาปัตยกรรมตัวเจน

## หลักการ

1. **แหล่งความจริงชุดเดียว** `world-layout.json` ถูกฝังเข้าโค้ด Luau ตอนส่ง ทั้งแผนที่ Python และแมพในเกมอ่านค่าเดียวกัน
2. **งานยาวไม่ค้าง Studio** ทุกขั้นรันใน `task.spawn` คืนค่าทันที ทำทีละก้อนแล้ว `task.wait()` เขียนความคืบหน้าเป็น Attribute `Progress` และ `Status` (`running` / `done` / `error: ...`) บน `workspace.WOLD` ตัว runner อ่านทุก 5 วินาที
3. **รันซ้ำได้** แต่ละขั้นสร้างของใน `workspace.WOLD.<ชื่อขั้น>` รันใหม่ลบ Folder เดิมก่อน ขั้น Terrain เริ่มด้วย `Terrain:Clear()`
4. **กำหนดผลได้** noise ใช้ `math.noise` กับ offset คงที่ การสุ่มใช้ `Random.new(seed)` รันกี่รอบก็ได้ผลเดิม
5. **ย่อส่วนก่อน** `SCALE = 0.125` ทำเกาะ 2,000 studs เจน 1 ถึง 2 นาที ปรับรูปเกาะจนพอใจแล้วรัน `SCALE = 1` (คาด 10 ถึง 20 นาที) อาคารไม่ย่อ ทดสอบขนาดจริงได้เพราะไม่ขึ้นกับขนาดเกาะ
6. **วางบนพื้นจริง** ตัวสร้างทุกตัวถาม `heightAt(x, z)` (ฟังก์ชันความสูงเดียวกับที่สร้าง Terrain รวมหุบแม่น้ำ) แล้ว `flattenPad` ปรับ Terrain ใต้ฐานเป็นลานเรียบก่อนวาง

|---|---|
| `mapgen/lib.lua` | PARAMS (SCALE, HALF, seed), LAYOUT (ฝังจาก JSON), จานสี, `heightAt`, `isLand`, `riverDepthAt`, ตัวเขียน Terrain แบบก้อน 256 × 256 studs ด้วย `WriteVoxels`, ตัวสร้างชิ้นส่วน (box, cylinder, house, tower, wallSegment, bridge แต่ละแบบ, pipe, gear, tree, crystal, pier, chimney), `flattenPad`, `progress`, `selfCheck` |
| `mapgen/00_setup.lua` | ลบ Baseplate และของทดสอบ สร้าง `workspace.WOLD` และ Folder ย่อย `StreamingEnabled = true` (MinRadius 512 TargetRadius 2048) Lighting + Atmosphere หมอกจบที่ 24,000 แผ่นทะเล Part 2,048 × 2,048 ปูจาก ±16,000 ถึง ±32,000 (ประมาณ 780 แผ่น CanCollide เปิด) |
| `mapgen/10_terrain.lua` | `Terrain:Clear()` แผ่นดินตามฟังก์ชันความสูง ทะเลและพื้นทะเลด้วย `FillBlock` ก้อนใหญ่ถึง ±16,000 ภูเขา หิมะ Crown Hill หน้าผา เกาะเล็ก 5 เกาะ โขดหิน 12 ก้อน |
| `mapgen/11_water_caves.lua` | หุบแม่น้ำ (อยู่ในฟังก์ชันความสูงแล้ว) เติมน้ำแม่น้ำและลำน้ำสาขาตามระดับที่ลดลงจากต้นน้ำถึงปากน้ำ ถ้ำ 3 แห่งเจาะด้วย `FillBall` อากาศต่อกันตามเส้น โถงใหญ่ คริสตัล (Neon + PointLight) สายแร่ (Part โลหะฝังผนัง) ซากเรือในถ้ำทะเล |
| `mapgen/20_roads_bridges.lua` | ทาวัสดุถนนบนผิว Terrain ตาม `roads` สะพาน 5 แห่งตาม `bridges` |
| `mapgen/30_capital.lua` | Brasshaven ทั้งหมดตามส่วนที่ 3 รวมกำแพง ประตูคำนวณจากจุดตัด SpawnLocation |
| `mapgen/40_villages.lua` | หมู่บ้าน 6 แห่ง แปลงนา ป้ายชื่อ |
| `mapgen/50_steam_magic.lua` | ราง สถานี 3 แห่ง รถไฟจอด ลิฟต์ไอน้ำ ท่อไอน้ำ Spire of Eld คริสตัลลอย |
| `mapgen/60_islands.lua` | สิ่งก่อสร้างบน 5 เกาะ |
| `mapgen/70_nature.lua` | ต้นไม้ พุ่มไม้ ก้อนหิน ตามกฎในส่วนที่ 4 เป็นชุดละ 500 ชิ้นแล้วพัก |
| `mapgen/90_verify.lua` | self-check ทั้งแมพ และพิมพ์รายการมุมกล้องสำหรับ `screen_capture` |
| `tools/run-luau.js` | `node tools/run-luau.js mapgen/10_terrain.lua [--scale 0.125]` รวม JSON + lib + ไฟล์ขั้น ส่ง `execute_luau` แล้ววนอ่าน Attribute จนจบ พิมพ์ความคืบหน้า และดึง `get_console_output` เมื่อ error |

## การตรวจงานหลังทุกขั้น

1. `get_console_output` ต้องไม่มี error จากขั้นนั้น
2. `selfCheck` ของขั้น: ตำแหน่งสถานที่ทุกแห่งเป็นพื้นดิน (ไม่ใช่ Water หรือ Air), Folder ของขั้นมีชิ้นส่วนมากกว่า 0, ไม่มีชิ้นส่วนต่ำกว่า Y = -100, จุดบนเส้นแม่น้ำ 20 จุดเป็น Water, SpawnLocation อยู่เหนือพื้น, จำนวนชิ้นรวมไม่เกิน 70,000
3. `screen_capture` จากรายการมุมกล้องท้ายเอกสาร ผมดูรูปแล้วแก้เอง ไม่ต้องให้ผู้ใช้แคป
4. ผ่านแล้ว `git commit` ทันที
