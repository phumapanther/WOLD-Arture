# โครงการสร้างสองโหมดใหม่ — ฟาร์มมิ่ง / PVP (วาง 2026-09-19)

ความต้องการทั้งหมดอยู่ใน `05-future-modes.md` **ไฟล์นี้ไม่ทวนความต้องการ** มันตอบคำถามเดียว:
*ถ้าจะลงมือ จะลงมือตรงไหน ด้วยอะไร และเรียงลำดับยังไงให้แต่ละขั้นเทสได้จริงก่อนไปขั้นถัดไป*

**ยังไม่เขียนโค้ดสักบรรทัด** — และมีสามเรื่องที่ต้องตัดสินใจก่อนเริ่ม Phase 1 (ท้ายไฟล์)

## 1. รูปทรงใหญ่: 1 Universe / 3 Places

```
Universe "WOLD Arture"  (universeId 10765335572)
├── Place: [Roplay] Arthur World  88774255487951   ล็อบบี้ + ช่อง Roleplay      ← มีอยู่แล้ว
├── Place: WOLD Farming          136992335889132   เกาะลอยฟ้า (Reserved รายคน)  ← **สร้างแล้ว 2026-09-20**
└── Place: WOLD Arena            ยังไม่มี            สนาม PVP 3v3                ← ต้องสร้าง
```

**เกาะอยู่ในเพลส `WOLD Farming` แล้ว** — ภูมิประเทศเกาะ + จุดเกิดที่ (0, 817, 0) · workspace สะอาด
(มีแค่ Terrain กับ `WOLD_SkyIsland`) · ไม่มีจุดเกิดหลงเหลือในความว่าง
เลขเพลสนี้คือค่าที่ `ChannelRegistry`/แท็บ Farming ในล็อบบี้ต้องใช้ตอนทำ Phase 1a

**ต้องเป็น Place แยกในจักรวาลเดียวกัน ไม่ใช่จักรวาลใหม่ และไม่ใช่เซิร์ฟในเพลสเดิม**

- *จักรวาลเดียวกัน* = **DataStore ก้อนเดียวกัน** โปรไฟล์ คลัง แคลน สหาย เงิน เพชร เลเวล ใช้ร่วมกัน
  ทันทีโดยไม่ต้องเขียนอะไรเลย — นี่คือข้อ "ข้อมูลเชื่อมกับเกมหลักทั้งหมด" ที่ผู้ใช้สั่ง ได้มาฟรีจากการเลือกนี้
  ถ้าแยกจักรวาลคือต้องทำสะพานข้อมูลเอง ซึ่งเป็นงานที่ไม่มีวันจบ
- *เพลสแยก* = แมพคนละชุด สคริปต์คนละชุด เพลสหลักไม่ต้องแบกเกาะกับสนามไว้ในไฟล์เดียวกัน
  (เพลสหลักมี terrain 16k + โมเดลเป็นหมื่น การยัดอีกสองแมพเข้าไปคือการทำให้ทุกคนโหลดของที่ไม่ได้ใช้)
- *ไม่ใช่เซิร์ฟในเพลสเดิม* = แมพถูกอบมากับเพลส การสร้างเกาะตอนรันคือการรอ mapgen ทุกครั้งที่มีคนเข้า

**ผลที่ตามมาที่ต้องยอมรับ**: โค้ดที่ใช้ร่วมกันต้องเดินทางไปสามเพลส — ดูข้อ 2

## 2. Phase 0 — แยกโค้ดที่ใช้ร่วมกันออกมา (งานที่ต้องทำก่อนทุกอย่าง)

ตอนนี้ `src/ServerScriptService/` คือ "ทุกอย่างของเกมหลัก" ถ้าเอาทั้งก้อนไปลงเพลสเกาะ เกาะจะมีมอนสเตอร์
อีเวนต์ไฟดับ พาหนะ และระบบยึดเมืองติดไปด้วย — ต้องแยกเป็นสามกอง

| กอง | ตัวอย่าง | ไปเพลสไหน |
|---|---|---|
| **แกนกลาง** (ระบบที่ทุกเพลสต้องมี) | `ProfileStore` `PlayerProfile` `Inventory` `Vitals` `PlayerMovement` `PlayerCombat` `WeaponSkills` `StatusEffects` `Progression` `ClanStore` `Friends` `Party` `AdminRoster` `AdminCommands` | ทั้งสาม |
| **เกมหลักเท่านั้น** | `Mobs` `WorldEvents` `Vehicle/*` `TownCapture` `TownVault` `IllegalFarm` `Transformers` `Quests` `Gathering` `Fishing` | เพลสหลัก |
| **ของเพลสนั้น** | ระบบคอกสัตว์ · แปลงปลูก · โซนแร่ (เกาะ) · รอบ/ร้าน/โหมดย่อย (สนาม) | เพลสนั้นเพลสเดียว |

`src/ReplicatedStorage/` (คอนฟิก แคตตาล็อก UI Remotes) **ใช้ร่วมกันทั้งสามเพลสทั้งก้อน** ไม่ต้องแยก —
ไฟล์พวกนี้เป็นข้อมูลกับตัววาด ไม่ได้สั่งให้อะไรเกิดขึ้นเอง

**วิธีทำใน Rojo**: ย้าย `src/ServerScriptService/` → `src/Server/Core/` กับ `src/Server/Main/` แล้วเพิ่ม
โปรเจ็คไฟล์ต่อเพลส โดยทั้งสามไฟล์ชี้ `$path` ไปที่ `Core` เหมือนกัน

```
default.project.json   → Core + Main        (เพลสหลัก เหมือนเดิมทุกประการสำหรับคนเล่น)
farming.project.json   → Core + places/farming/server
arena.project.json     → Core + places/arena/server
```

⚠️ **นี่คือการขยับไฟล์ทั้งโฟลเดอร์ ซึ่งทุกไฟล์ที่เขียน `require(game.ServerScriptService.X)` จะยังทำงานได้
ตามเดิม** (พาธนั้นอ้างถึงที่อยู่ **ในเพลส** ไม่ใช่ที่อยู่บนดิสก์) — Rojo จะยังวางทุกอย่างไว้ใต้
ServerScriptService เหมือนเดิม เปลี่ยนแค่ว่าไฟล์ไหนถูกหยิบไปเพลสไหน **ห้ามเปลี่ยนชื่อ instance ระหว่างทาง**

**เทสว่า Phase 0 ผ่าน**: เพลสหลักยังเล่นได้ครบเหมือนเดิม โดยยังไม่มีเพลสใหม่สักเพลส

## 3. Phase 1 — เกาะฟาร์มมิ่ง: ทางเข้าก่อน เนื้อหาทีหลัง

### 3.1 ทางเข้า (เรื่องที่ยากที่สุดของโหมดนี้ ทำก่อน)

ล็อบบี้ปัจจุบันจองเซิร์ฟผ่าน `Lobby/ChannelRegistry.lua` อยู่แล้ว (`TeleportService:ReserveServer` +
DataStore เก็บ accessCode + ทางกลับ `code_<privateServerId>` ไว้ให้เซิร์ฟรู้ว่าตัวเองคือช่องไหน)
**เกาะใช้โครงเดียวกันเป๊ะ ต่างแค่กุญแจ**: จากเดิม "ช่องที่ 3 ของโหมด Roleplay" เป็น "เกาะของ userId 4871683651"

```
farm_<ownerUserId>        = { accessCode, privateServerId, createdAt }
farmcode_<privateServerId> = { ownerUserId }        ← เซิร์ฟเกาะอ่านตอนบูตเพื่อรู้ว่าตัวเองเป็นเกาะของใคร
farmguests_<ownerUserId>   = { [userId] = ชื่อ }     ← คนที่ถูกชวน (ดูข้อ 3.3)
```

- แท็บ **Farming** ในล็อบบี้ไม่ได้โชว์ "ช่อง 1-5" แต่โชว์ **เซิร์ฟของคุณเอง** (ถ้ามี VIP) + **เซิร์ฟที่คุณถูกชวน**
  แถวละหนึ่งเจ้าของ ชื่อแถว = "เซิร์ฟของ &lt;ชื่อ&gt;" ตามที่ผู้ใช้สั่ง
- ไม่มี VIP → แถวของตัวเองขึ้นเป็นปุ่ม "ต้องมี VIP" ไม่ใช่ซ่อนเฉยๆ (ปุ่มที่หายไปไม่ได้ขายอะไรให้ใคร)
- **ด่านจริงอยู่ที่เซิร์ฟเกาะ ไม่ใช่ที่ปุ่ม**: เกาะรู้ว่าตัวเองเป็นของใครจาก `farmcode_*` พอมีคนเข้ามา
  ถ้าไม่ใช่เจ้าของและไม่อยู่ในรายชื่อแขก → เด้งกลับล็อบบี้ทันที (บทเรียนเดียวกับทุกระบบ: ปุ่มคือทางเข้า
  ที่สะดวก ไม่ใช่กฎ — ไคลเอนต์ยิง teleport เองได้)

### 3.2 VIP

ยังไม่มีระบบ VIP ในเกม — **ต้องตัดสินใจก่อน** (ดูท้ายไฟล์) โครงที่เตรียมไว้รองรับทั้งสองทาง:

- ซื้อด้วยเพชร → เก็บ `profile.VipUntil = os.time() + n` อ่านจาก `PremiumConfig` เหมือนของพรีเมียมอื่น
- ขายด้วยโรบัค (Game Pass) → `MarketplaceService:UserOwnsGamePassAsync` แคชไว้ต่อเซสชัน

ทั้งสองทางซ่อนหลังฟังก์ชันเดียว `Vip.Has(player)` → **ระบบที่เหลือไม่ต้องรู้ว่ามันมาจากไหน**
เปลี่ยนวิธีขายวันหลังก็แก้ไฟล์เดียว

### 3.3 ชวนเพื่อน (NPC กลุ่มขวาล่างของเกาะ)

คนที่ถูกชวนอาจอยู่คนละเซิร์ฟ — เซิร์ฟหนึ่งสั่งเทเลพอร์ตคนที่ไม่ได้อยู่ในเซิร์ฟตัวเองไม่ได้
ใช้ **MessagingService** ซึ่งโปรเจ็คใช้อยู่แล้วกับ heartbeat ของช่อง:

```
เจ้าของกด "ชวน X" ที่เกาะ
   → เขียนชื่อ X ลง farmguests_<owner>   (สิทธิ์ถาวรจนกว่าจะถูกถอด)
   → PublishAsync("FarmInvite_<XUserId>", { owner, ชื่อเจ้าของ, accessCode })
   → เซิร์ฟที่ X อยู่รับได้ → เด้งหน้าต่างถาม (ยืม `ClassActionGui:AskConsent` เหมือนคำชวนเข้าตี้)
   → ตกลง → TeleportToPrivateServer ไปเกาะนั้น
```

X ไม่ออนไลน์ = ไม่มีใครรับข้อความ แต่ชื่อถูกบันทึกแล้ว **แถวเกาะนั้นจึงโผล่ในล็อบบี้ของเขาเองทีหลัง**
(นี่คือเหตุผลที่สิทธิ์ต้องอยู่ใน DataStore ไม่ใช่อยู่ในข้อความ)

### 3.4 แมพเกาะ — **ตัวเกาะเขียนเสร็จแล้ว 2026-09-19**

`mapgen/80_sky_island.lua` — เกาะลอยฟ้าเปล่าๆ ตามภาพอ้างอิงที่ผู้ใช้ส่งมา **ยังไม่มีของบนเกาะเลย
ตามที่ผู้ใช้สั่ง (จะตกแต่งเอง)** · ภาพผลลัพธ์: `docs/shots/island-hero.png` · `island-top2.png` · `island-under.png`

- รัศมี 220 (กว้าง 440 สตัด) · โดมกลางเกาะ 16 · ลึกถึงปลายแหลม 300 · หญ้า 12 + ดิน 14 + หินที่เหลือ
- **ยืนได้ด้วยตัวเอง ไม่ใช้ `lib.lua` และไม่ใช้ world-layout** เพราะปลายทางคือเพลสเปล่า:
  `node tools/run-luau.js mapgen/80_sky_island.lua --no-lib`
- ตัวเลขทั้งหมดอยู่หัวไฟล์ (R · DOME · GRASS · DIRT · DEPTH · TAPER · RIM · EDGE_NOISE · OVAL · SPIKES)
- **ไม่แตะอะไรนอกกล่องของตัวเอง** (ไม่ `Terrain:Clear()`) และ **กันรันผิดเพลส**: ในเพลสหลักจะไม่ทำงาน
  จนกว่าจะตั้ง `workspace:SetAttribute("SkyIslandOrigin", Vector3.new(x, y, z))` เอง — ใช้ดูรูปทรงไกลๆ นอกแมพ
- ลบพรีวิวทิ้ง: `workspace:SetAttribute("SkyIslandErase", true)` แล้วรันไฟล์เดิมอีกครั้ง

**สองบทเรียนจากรอบแรกที่เขียนไว้ในไฟล์แล้ว** (อย่าแก้ย้อน):
1. **ขอบเกาะต้องหนาขั้นต่ำ (`RIM`)** ถ้าปล่อยให้บางลงเป็นศูนย์ที่ขอบ วอกเซลแถวสุดท้าย occupancy บางเฉียบ
   แล้วตัวปั้นผิวของ Roblox ดันมันออกมาเป็น **ครีบแหลมรอบเกาะ**
2. **ความถี่ noise รอบวงชี้ขาดว่าได้เกาะหรือได้รูปหลายเหลี่ยม** — เดินรอบวงในสเปซ noise ด้วยรัศมีเล็ก
   (~1.5) ได้ลอนใหญ่ 3-4 ลอน = หกเหลี่ยมชัดเจน ต้องใช้ 3.0 ขึ้นไปพร้อมลดแอมพลิจูด

**ของที่จะวางบนเกาะทีหลัง** ตามผังในข้อ 1 ของ `05-future-modes.md` (บ่อน้ำซ้ายบน · บ้านกลางบน ·
โซนแร่ขวาบน · ลาน 3x3 กลาง · บอร์ดเควสซ้ายล่าง · NPC ขวาล่าง · คอกสัตว์) ใช้ `modelkit/` ที่มีอยู่ —
บ้าน เตา ตู้เย็น เตียง NPC มีของพร้อมหมดแล้ว **ไม่ต้องปั้นใหม่**

### 3.5 ระบบบนเกาะ

| ของบนเกาะ | ใช้ของเดิมได้เลย | ต้องเขียนใหม่ |
|---|---|---|
| ตกปลาในบ่อ | `Fishing.server` + `FishingConfig` | ตัวคูณเรทของเกาะ (เมธอดเดียว) |
| บ้าน: เตียง/เตา/ตู้เย็น/ตู้ยา | `Beds` `CraftStations` `StorageChests` | ปลดเงื่อนไขอาชีพให้เจ้าของเกาะ |
| คลัง/ตลาด/บอร์ดเควส | `Vault` `MarketAccess` `GuildBoard` | NPC ตัวใหม่บนเกาะเท่านั้น |
| **คอกสัตว์ 3 คอก** | — | `FarmPens.server` + `PenConfig` (ตัวจับเวลา + กองของ + ปลดคอกด้วยเพชร) |
| **แปลงปลูก 9 ช่อง** | `GatherConfig` เป็นต้นแบบของ "จุดที่ให้ของ" | `FarmPlots.server` (เมล็ด → เวลา → ผลผลิต) |
| **โซนแร่ปลดด้วยเพชร** | `Gathering.server` ทำงานกับจุดที่มีแท็กอยู่แล้ว | ตัวสุ่มจุดเกิดแร่ + ด่านปลดโซน |

**ของบนเกาะเซฟที่ไหน**: `profile.Farm = { pens = {...}, plots = {...}, mineUnlocked = bool }`
อยู่ในโปรไฟล์เจ้าของ ไม่ใช่ใน DataStore ของเกาะ — เกาะคือ "ของเล่นของคนคนนั้น" ไม่ใช่สถานที่ในโลก

## 4. Phase 2 — สนาม PVP

### 4.1 ล็อบบี้ของตัวเอง

เพลส Arena มีล็อบบี้ของมันเอง (ไม่ใช่ล็อบบี้ของเกมหลัก) — คนเข้ามาจากแท็บ PVP แล้วมาโผล่ที่นี่
ตั้งตี้ ≤3 คน (ใช้ `Party.lua` ตัวเดิมได้ทั้งดุ้น มันเป็นโมดูลสถานะที่ไม่รู้จักแมพ) แล้วกดหาคู่

### 4.2 จับคู่ 3v3

เซิร์ฟล็อบบี้ของ Arena ถือคิว: ตี้ + คนเดี่ยว → ครบ 6 คน → `ReserveServer` แมพสุ่ม → ส่งทั้งหกไปด้วย
`TeleportData = { mapId, modeId, teams }` **เซิร์ฟแมตช์ไม่เชื่อ TeleportData เรื่องทีม** แต่ยืนยันกับ
DataStore/MessagingService อีกชั้น (ไคลเอนต์แก้ TeleportData ไม่ได้ แต่ระบบที่เชื่อข้อมูลขามาอย่างเดียว
จะพังทันทีที่มีใครเข้าผิดเซิร์ฟ)

**แอดมินเข้าเล่นคนเดียวได้** (ผู้ใช้สั่ง): `AdminRoster.Has(player)` → ปุ่ม "เริ่มเลย" ในล็อบบี้ Arena
ที่ข้ามคิว จองเซิร์ฟ แล้วเข้าไปคนเดียว/ทีมไม่ครบ — ใช้เป็นทางเทสระบบรอบ/ร้าน/โหมดย่อยทั้งหมดโดยไม่ต้องหาคนหกคน
**นี่คือสิ่งที่ทำให้ Phase 2 เทสได้จริงตั้งแต่วันแรก** จึงต้องทำ *ก่อน* ระบบจับคู่ ไม่ใช่ทีหลัง

### 4.3 รอบ ร้าน และเงินในแมตช์

- `ArenaConfig.lua` ถือทุกตัวเลข: ซิลเวอร์เริ่มต้น · รางวัลต่อรอบ · ราคาของ 13 ชิ้น · เงื่อนไขชนะของสามโหมดย่อย
- **ซิลเวอร์ในแมตช์เป็นตัวเลขในหน่วยความจำของเซิร์ฟแมตช์ ไม่ใช่ไอเทม `Silver`** (ผู้ใช้ยืนยันแล้ว)
  จบแมตช์แล้วหายไปพร้อมเซิร์ฟ — ไม่มีทางรั่วเข้าเกมหลัก เพราะไม่เคยมีตัวตนในกระเป๋าเลย
- ของที่ซื้อ: `Inventory` ตัวเดิมของเซิร์ฟนั้น (กระเป๋าในแมตช์เป็นคนละใบกับกระเป๋าเกมหลัก — เซิร์ฟแมตช์
  **ไม่โหลดโปรไฟล์ของจริง** โหลดแค่ ชื่อ/เพื่อน/เงิน/เพชร ตามที่ผู้ใช้สั่ง) ⚠️ ข้อนี้ต้องระวังที่สุด:
  ถ้าเผลอโหลดโปรไฟล์เต็มแล้วเซฟตอนจบ กระเป๋าจริงของคนเล่นจะถูกทับด้วยของในแมตช์
- ปุ่ม F ใช้ยา · ซื้อแล้วสวมทันที · อย่างละ 1 ต่อรอบ (ดู `05-future-modes.md` §2)

## 5. ลำดับงานที่เทสได้ทีละขั้น

| ขั้น | ได้อะไรเมื่อจบ | เทสยังไง |
|---|---|---|
| 0 | แยก Core/Main เสร็จ เพลสหลักยังเหมือนเดิม | เล่นเพลสหลักให้ครบเหมือนเดิม |
| 1a | เพลส Farming เปล่าๆ + ทางเข้าจากล็อบบี้ + ด่านกันคนนอก | เข้าเกาะตัวเองได้ · บัญชีที่สองเข้าไม่ได้ |
| 1b | แมพเกาะ + บ้าน + NPC สามตัว + บ่อปลา | เดินครบเกาะ ใช้เตา/เตียง/คลังได้ |
| 1c | คอกสัตว์ · แปลงปลูก · โซนแร่ · ชวนเพื่อน | ครบโหมดฟาร์มมิ่ง |
| 2a | เพลส Arena + ล็อบบี้ + **ปุ่มแอดมินเริ่มคนเดียว** | แอดมินเข้าแมพว่างได้ |
| 2b | ร้านซื้อของ + รอบ + สามโหมดย่อย | แอดมินเล่นจบแมตช์คนเดียวได้ |
| 2c | จับคู่ 3v3 จริง + รางวัลเข้าเกมหลัก | หกบัญชี หรือเปิดให้คนเล่นจริง |

## 6. สามเรื่องที่ต้องตัดสินใจก่อนเริ่ม Phase 1

1. **VIP ขายยังไง** — เพชร (มีอยู่แล้ว ควบคุมเองได้) หรือ Game Pass โรบัค (เก็บเงินจริง แต่ต้องตั้งใน
   เว็บ Roblox) · รายเดือนหรือตลอดชีพ · VIP หมดอายุแล้วเกาะหายหรือแค่เข้าไม่ได้
2. **เกาะของคนที่ไม่ออนไลน์** — เพื่อนเข้าเกาะตอนเจ้าของไม่อยู่ได้ไหม (ถ้าได้ ของที่เก็บได้บนเกาะเป็นของใคร)
3. **ตัวเลขของ Phase 1c** — คอกรอบละกี่นาที · ราคาเพชรของคอกที่ 2-3 และโซนแร่ · เมล็ดกี่ชนิด ปลูกนานเท่าไหร่

ข้อ 1 กับ 2 ปิดทางเข้าทั้งหมด (ทำ 1a ไม่ได้ถ้ายังไม่ตอบ) ส่วนข้อ 3 ค่อยตอบตอนถึง 1c ได้
คำถามที่เหลือของทั้งสองโหมดอยู่ท้ายแต่ละหัวข้อใน `05-future-modes.md` ตามเดิม
