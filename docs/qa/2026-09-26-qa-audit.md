## 🔴 วิกฤต

**C1 · `Inventory.AddItem` คืน `false` ทั้งที่ของเข้าคลังไปแล้ว — ต้นเหตุเดียวของการปั๊มของ 7 ทาง (ผู้เล่นปกติทำได้)**
`Inventory.lua:194-201` ทางกระเป๋าเต็มส่งของทั้งก้อนเข้าคลังมาดาม (`SpillOver`) แล้ว `return false` เสมอ
ผู้เรียกทุกตัวอ่านว่า "ไม่ได้ให้อะไร" จึงไม่หักของจากต้นทาง:
- ซื้อของร้านตอนกระเป๋าเต็ม → ของเข้าคลังฟรี ไม่เสียเงิน/เพชร กดซ้ำได้จนคลังเต็ม (`Shop.server.lua:279-291`)
- "ให้ของ" คนที่กระเป๋าเต็ม → คนให้ยังมีของ คนรับได้ในคลัง (`ClassActions.server.lua:318`) รวมอาวุธ +10 กุญแจรถ
- หยิบจากคลังแคลน/คลังเมือง ตอนกระเป๋าเต็ม → ของคืนคลังกลาง + อยู่ในคลังส่วนตัวด้วย (`Clans.server.lua:604`, `TownVault.server.lua:212`)
- หยิบจากท้ายรถ (`Vehicle/Service.lua:938`) · หยิบจากหีบสมบัติ (`TreasureChests.server.lua:246,265`)
- ซื้อชุดเมล็ดตอนกองเกือบเต็ม ได้บางเม็ดไม่เสียเงิน (`Shop.server.lua:280-291`)
- ข้อความผิดตามมา: "ปลาหลุด/ของหล่นหาย/ของที่สร้างหาย" ทั้งที่ของเข้าคลัง (`Fishing:415`, `IllegalFarm:167`, `Gathering:375`, `Crafting:456`)
แก้: ทางกระเป๋าเต็มคืนผลของ `SpillOver` (true = ทุกชิ้นมีที่อยู่) — **แก้บรรทัดเดียวปิดทั้งตระกูล** แล้วไล่ดูผู้เรียกที่
เคยพึ่ง false = "กระเป๋าเต็ม" (ร้านค้าคิดเงินตามที่เข้าจริง)

**C2 · รางวัลแบทเทิลพาสเคลมซ้ำได้ไม่จำกัด** `PremiumStore.server.lua:327-334`
ของที่มีเพดานพก (อาหาร) เข้าได้บางชิ้น → `give` คืน false → ปลดธง "รับแล้ว" ทั้งที่ของบางส่วนเข้าไปแล้ว → กดรับใหม่ได้
แก้: ห้ามปลดธงหลัง AddItem ทำงานแล้ว · เช็ค `RoomUnderLimit` + ที่ในคลังก่อนตั้งธง

**C3 · เทรด: สลับของหลังอีกฝ่ายกดตกลง + หน้าต่างเทรดพัง** (ผู้เล่นปกติทำได้)
- ข้อเสนอเก็บแค่เลขช่อง (`Trading.server.lua:118-134, 281-298`) — A เสนอเพชร 99 · B กดตกลง · A จัดกระเป๋า/ทิ้ง/ขาย
  ให้ช่องนั้นเหลือหิน 1 ก้อน แล้วกดตกลง → B ได้หิน
- `UI/TradeGui.lua:329` พังที่ช่องว่างแรก (ช่องว่างส่งมาเป็น `false`) → ไม่เคยเห็นข้อเสนอของอีกฝ่ายเลย ตกลงแบบตาบอด
แก้: จำ id/จำนวน/meta ต่อช่องตอนเสนอ ไม่ตรงตอนสรุป = ยกเลิก · `if slot then` ใน RenderBag

**C4 · นักบวชฮีล / ช่างซ่อม หักเงินเป้าหมายโดยไม่ต้องยินยอม** `ClassActions.server.lua:193-238`
ยืนใกล้ใครก็ได้ กด "ฮีลใหญ่" รัวๆ = ดูด 2,000 ต่อครั้ง เลือดเต็มก็หัก · ช่าง 2,500 ต่อครั้งถ้าของสึกนิดเดียว
แก้: ผ่าน `AskConsent` เหมือนการอุ้ม · ปฏิเสธเมื่อเลือดเต็ม

**C5 · ข้อความที่ผู้เล่นพิมพ์ไม่ผ่านตัวกรองของ Roblox — เสี่ยงเกมโดนลงโทษ/ปิด**
บอร์ดกิลด์ (`GuildBoard.lua:27-56` ส่งให้ทุกคน) · นกพิราบ (`Friends.lua:203-240`) · ชื่อ/คำอธิบายแคลน (`ClanStore.lua:262-296`) ·
`/announce` ของอาชีพ/แอดมิน (`AdminCommands.server.lua:1008,1054`) · ชื่อคนดู TikTok บนป้ายบอส
แก้: ผ่าน `Announce.Filter` / `TextService` ที่มีอยู่แล้ว กรองไม่ได้ = ไม่ส่ง

**C6 · โซนแร่บนเกาะขุดได้ไม่จำกัด** `IslandZones.server.lua:393-451`
ก้อนแร่ไม่มี `OneShot` → ขุดแล้วไม่หาย เกิดซ้ำทุก 60 วิ และมีปุ่มฟาร์มออโต้ → ทองคำ/แร่เวท/เพชรไม่จำกัด ยืน AFK ได้
เก็บโซนแล้ววางใหม่ได้ก้อนแรกทันทีด้วย · แก้: ตั้ง `OneShot` + `Uid` แบบ IslandNodes

**C7 · คนที่ถูกจับกุม/ถูกยิงล้ม/มึนหัว ยังโจมตีได้** `PlayerCombat.server.lua:600-607`, `WeaponSkills.server.lua:425-431`
นักโทษยืนหน้าทหารยาม 3.5 สตัด ฟันทหารยามล้ม → หลุดเป็นอิสระ ได้ EXP ทหารยามโดนหัวแดง
แก้: ด่าน `canFight` เดียว (ไม่ล้ม ไม่ถูกยิงล้ม ไม่มึน ไม่ถูกจับ ไม่ถูกอุ้ม) ใช้ทั้งโจมตี สกิล กลิ้ง

**C8 · คนที่ยอมให้อุ้มกลายเป็นอมตะ + ยิงได้ + ลงเองไม่ได้** `Vitals.lua:357`, `PlayerRescue.server.lua:237-249`
`IsInvulnerable` เป็นจริงตลอดที่ถูกอุ้ม → ป้อมปืนอมตะไม่จำกัดเวลา · อยากลงก็ลงไม่ได้ (คนอุ้มเท่านั้นกดได้)
แก้: อมตะเฉพาะคนที่ล้มแล้วถูกอุ้ม · ห้ามโจมตีตอนถูกอุ้ม · ให้คนถูกอุ้มกดลงเองได้ (มีปุ่มมือถือ)

**C9 · ส่งจำนวน NaN → กองของไม่มีวันหมด / ล้างเงินคนอื่น (ต้องใช้โปรแกรมโกง)**
`RemoveFromSlot`/`AddGold` รับ NaN · ทางเข้า: ฝากหีบสาธารณะ (`StorageChests:140`), ให้ของ/ให้เงิน (`ClassActions:95-108, 312`),
ขาย (`Shop:321`, `TownBuyers:140`), เงินในเทรด (`Trading:298`), ฝากคลังแคลน/เมือง
ผล: ซิลเวอร์/แบบแปลน/แร่ ใช้คราฟและตีบวกได้ไม่จำกัด · แก้: ปฏิเสธ `x ~= x` และ inf ที่ต้นทาง + ทุก handler

**C10 · ฝากเข้าคลังแคลน/คลังเมือง แล้วสวม/ให้ของระหว่างรอ DataStore → ของซ้ำ** (ต้องใช้โปรแกรมโกงหรือจังหวะเป๊ะ)
`Clans.server.lua:551-581`, `TownVault.server.lua:162-191` เขียนเข้าคลังก่อนแล้วค่อยหักจากกระเป๋าตามเลขช่อง
แก้: หักจากกระเป๋าก่อน (ไม่ yield) เขียนไม่สำเร็จค่อยคืน

- "พิมพ์ `/tp` หนีคุก" → แชทถูกซ่อนในเซิร์ฟเกม ผู้เล่นปกติพิมพ์ไม่ได้ (เหลือแต่โปรแกรมโกงซึ่งย้ายตัวเองได้อยู่แล้ว) — ลดเป็นต่ำ
- "การ์ดเลือกอาชีพปิดไม่ได้" → ผิด มีปุ่มข้ามอยู่ (บรรทัด 212) — เหลือแค่ปัญหาปุ่มข้ามทับการ์ดบนมือถือ (M15)
