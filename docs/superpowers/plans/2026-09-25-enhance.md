# ตีบวกอาวุธ +1 ถึง +10 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** แท็บ "ตีบวก" ที่ช่างตีเหล็ก: ยื่นอาวุธต่อสู้ + วัสดุ → แถบเวลา 4 วิ → สำเร็จได้ +1 (ดาเมจเพิ่ม) / แตกเสียความคงทน 10% → อาวุธคืนกระเป๋า (เต็ม/ออกเกม = เมล)

**Architecture:** ข้อมูลล้วนใน `EnhanceConfig` (ReplicatedStorage) · ขั้นอยู่ที่ `meta.enhance` บนตัวอาวุธ · ฝั่งเซิร์ฟเวอร์ต่อเข้า `Crafting.server` (ใช้ nearSmith / countMaterial / takeMaterial / snapshot / ล็อก `Busy.smith` เดิม) · แถวตีบวกหน้าตาเดียวกับแถวสูตร (`recipeRow` เดิม + ข้อความ/ปุ่มที่ override ได้) · ดาเมจคูณที่จุดคิดดาเมจเดิมสามจุด

**Tech Stack:** Roblox Luau · Studio MCP (`tools/lua.js`, `tools/push.js`, `tools/syntax.js`)

**Spec:** `docs/superpowers/specs/2026-09-24-enhance-design.md`
