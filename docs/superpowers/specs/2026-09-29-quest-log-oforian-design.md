# แถบเควสรวม + เควสของออฟาเรียน เทพหุ่นฟาง + เกาะลอยฟ้าแห่งความฝัน — สเปก

ผู้ใช้อนุมัติทีละส่วน 2026-09-29 (ส่วน 1-4 ตอบ "โอเค" ทุกข้อ) · ต่อจาก `2026-09-26-v1.5-roadmap-design.md` เฟส 4 (เนื้อเรื่อง)

## เป้าหมาย

- ผู้เล่นเห็นเควสทุกอย่างที่ถืออยู่ในแถบเดียว ซ้อนกันได้ แยกสีตามชนิด และ **จิ้มแล้วระบบนำทางพาไป** (คอมกด T เดินตามได้)
- ของขวัญทั้งหมดจากหุ่นฟางเปลี่ยนจาก "กด E รับของ" เป็น **เควสสีฟ้าที่มีเรื่องเล่า** โดยเทพหุ่นฟาง "ออฟาเรียน"
- Lv.5 ได้เควส "เกาะลอยฟ้าแห่งความฝัน": รับ VIP 30 วัน → คัทซีนรถคาร์โก้ → **วาปไปเกาะฟาร์มของตัวเองตรงๆ**
- จบบทไลราแล้วเห็นเควสบทถัดไป (ซอลต์เมียร์) ในสภาพ **ล็อก** ให้รู้ว่ามีต่อ

## การตัดสินใจของผู้ใช้ (2026-09-29)

| เรื่อง | คำตอบ |
|---|---|

| ของขวัญการเดินทาง (หลังจบบทไลรา) | **150 เพชร บัญชีใหม่เท่านั้น** (ย้ายของเดิมมาเป็นเควส) |

| ที่วางแถบ | **ขวาบนที่เดิม แต่อยู่ใต้หน้าต่าง ย่อได้** · มือถือเริ่มแบบย่อ · คอมเริ่มแบบขยาย (แก้ QA U1 ไปในตัว) |

| กด T เดินออโต้ | ทำเสร็จแล้ว (commit `b4ac3b9`) — แถบนี้แค่ปักหมุดให้ |

## ส่วนที่ 1 — แถบเควสรวม (QuestLog)

**แหล่งข้อมูลสามทาง รวมเป็นรายการเดียวฝั่งไคลเอนต์**

| แหล่ง | ใครส่ง | ในเพลส |
|---|---|---|
| เควสหลัก (บทเนื้อเรื่อง + แถวล็อกของบทถัดไป) | `Story.server` ขยาย `StoryState` | เกมหลักเท่านั้น (Story.server รันที่นั่นที่เดียว) |
| เควสรองของออฟาเรียน | `Story.server` ใน `StoryState` ก้อนเดียวกัน | เกมหลักเท่านั้น |
| งานบอร์ด (ที่ถืออยู่ ≤ 3) | `Quests.server` ส่ง `QuestLogBoard` ใหม่ | เกมหลัก + เกาะ (บอร์ดรวมบนเกาะ) |

- ไคลเอนต์รวมด้วยกติกาล้วน `QuestLogRules.Merge(storyRows, boardRows)` → เรียง: ทอง (บทที่เล่นอยู่ → แถวล็อก) → ฟ้า → ขาว
- **แถวหนึ่ง** = `{ key, color = "main"|"side"|"board", title, goal, progress = "3/5"?, state = "active"|"done"|"waiting"|"locked", reason? }`
  · `done` = งานบอร์ดของครบแล้ว (เหลือส่ง) · `waiting` = ยังรับไม่ได้ชั่วคราว (เช่นพาสเดือนนี้ปลดแล้ว) · `locked` = ยังไม่เปิด
  · `waiting` กับ `locked` วาดจางลง + 🔒 · จิ้ม = ข้อความเหตุผล (`reason` หรือ "เควสนี้ยังไม่เปิด")
- **UI** `UI/QuestTrackerGui.lua` (ใหม่ แทนแผง tracker ใน `StoryGui`) + ต่อสายใน `StoryController` (มันถือ StoryState อยู่แล้ว)
  · ขวาบนตำแหน่งเดิม (`1,-12, 0,150`) · หัว "📜 เควส (N)" แตะย่อ/ขยาย · คอมเริ่มขยาย มือถือเริ่มย่อ (`Responsive.IsTouchOnly`)
  · **DisplayOrder ต่ำกว่าหน้าต่างทุกบาน** (เดิม 900 = ต้นเหตุ QA U1) · ขยายแล้วสูงสุด 45% ของจอ เกินนั้นเลื่อนได้
  · แถวใหม่โผล่ = ข้อความ "📜 เควสใหม่: <ชื่อ>" + เสียง ครั้งเดียวต่อเควส (`profile.Data.Story.pop[key] = true`)
- **จิ้มแถว = นำทาง**: ไคลเอนต์ส่ง `RequestQuestNav(key)` → เซิร์ฟเจ้าของแถวนั้น (`story:*`/`side:*` = Story.server · `board:*` = Quests.server)
  หาจุดที่ใกล้ตัวที่สุด → ส่ง `QuestNav(position, label)` กลับ → `Navigation.Active:SetDestination` + ปักบนแผนที่
  · **ทำไมเซิร์ฟหาจุด**: เกมเปิด StreamingEnabled ไคลเอนต์มองไม่เห็นสปอว์เนอร์/จุดเก็บที่อยู่ไกล
  · จิ้มแถวที่กำลังนำทางอยู่ซ้ำ = เลิกนำทาง · หาจุดไม่เจอ = "ไม่มีจุด <ชื่อ> ในแมพนี้"

**เป้านำทางแยกตามชนิด** (กติกาหาแหล่งของอยู่ในโมดูลล้วน `QuestNavRules` อ่านจาก `GatherConfig` เทสได้)

| ชนิด | ไปไหน |
|---|---|
| talk (เนื้อเรื่อง) | NPC ของขั้นนั้น (ไลรา) |
| deliver (เนื้อเรื่อง) | ของยังไม่ครบ → แหล่งของที่ใกล้สุด (จุดเก็บที่ให้ของนั้น หรือสปอว์เนอร์มอนที่ดรอป) · ครบแล้ว → NPC |
| hunt (เนื้อเรื่อง/บอร์ด) | สปอว์เนอร์ของมอนชนิดนั้นที่ใกล้สุด (ข้ามสปอว์เนอร์ `EventOnly`) |
| reach (เนื้อเรื่อง) | หมุดความทรงจำ |
| gather (บอร์ด) | จุดเก็บที่ให้ของนั้นใกล้สุด (`NodeKind` ที่ `item`/`roll` มีของนั้น) |
| fish (บอร์ด) | จุดตกปลาใกล้สุด |
| งานบอร์ดของครบ | บอร์ดเมืองของงานนั้น (บอร์ดรวม = บอร์ดที่ใกล้สุด) |
| เควสฟ้าทุกอัน | หุ่นฟาง `Dummy_Spawn` |

- **บนเกาะ**: แถบมีแต่งานบอร์ด (เนื้อเรื่อง/ออฟาเรียนเล่นในเกมหลัก) · นำทางหาของในเกาะ ไม่มี = ข้อความ "ไม่มีจุด … ในแมพนี้"

## ส่วนที่ 2 — เควสสีฟ้าของออฟาเรียน เทพหุ่นฟาง

**สี่เควส อย่างละครั้งต่อบัญชี · ไม่มีที่เก็บสถานะใหม่** — "เควสนี้ยังค้างอยู่" คำนวณจากธงของขวัญเดิมทั้งหมด (`VipGift`)
สิทธิ์เดิมจึงเป็นสิทธิ์เดียวกัน คนที่รับของขวัญไปแล้วไม่มีเควสนั้นเอง

| key | ชื่อ | โผล่เมื่อ | ของ | กติกา (ธงเดิม) |
|---|---|---|---|---|
| `side:newcomer` | ของขวัญผู้มาใหม่ | บัญชีใหม่ ตั้งแต่เข้าเกม | พาสพรีเมียมเดือนนั้น | `CheckPass` · เดือนนั้นปลดเองแล้ว = `waiting` "รับได้เดือนหน้า" |
| `side:sky` | เกาะลอยฟ้าแห่งความฝัน | Lv.5 (โผล่ทันทีที่ขึ้นเลเวล) | VIP 30 วัน (มีอยู่ = ทบ) → คัทซีน → วาป | `VipGiftClaimed` · **ถอดด่าน "มี VIP อยู่แล้ว" ออก** |
| `side:travel` | ของขวัญการเดินทาง | จบบท "ความทรงจำแรก" · บัญชีใหม่ | 150 เพชร | `CheckGems` |
| `side:friends` | สายใยมิตรภาพ | เพื่อนในเกมครบ 5 คน | ออร่าสุ่ม | `CheckAura` · กระเป๋าเต็ม = เควสยังค้าง บอกให้เคลียร์ช่อง |

- `VipGift.Quests(data, now, level, friends, pool, hasPremium)` ใหม่ (กติกาล้วน) คืนรายการแถวฟ้าจากฟังก์ชัน Check เดิม
  · ก่อนถึงเงื่อนไข **ไม่มีแถวเลย** (ผู้ใช้สั่ง "พอเวล 5 เควสเด้งทันที") ยกเว้นพาสที่ `waiting`
- **ปุ่ม E บนหุ่นฟาง = "คุยกับออฟาเรียน"** (แทน "รับของขวัญ") · ป้ายชื่อเหนือหัว "ออฟาเรียน เทพหุ่นฟาง" · ❗ เหนือหัวตอนมีเควสฟ้าพร้อมรับ
  · คุยหนึ่งครั้ง = เล่นบทพูดของเควสที่พร้อมทีละอัน (ลำดับตามตาราง) แล้วให้ของทีละอัน · ไม่มีอะไรค้าง = บทพูดทักทาย
  · `side:sky` เป็นอันเดียวที่มี **ปุ่ม "รับพร"** ท้ายบทพูด (ไม่กด = ปิดไปแล้วกลับมาคุยใหม่ได้ เควสยังอยู่)
- ของขวัญเดิม `VipGiftPrompt` ถูกแทนที่: ป้าย/ข้อความ "ของขวัญที่ยังรอ" หายไป เพราะแถบเควสบอกแทนแล้ว

## ส่วนที่ 3 — คัทซีนรถคาร์โก้ + วาป (~25 วิ มีปุ่มข้าม)

1. ออฟาเรียนพูดจบ → กด **"รับพร"** → เซิร์ฟให้ VIP ทันที (ปั๊ม `VipGiftClaimed` + จด `Story.skyWelcome = true`) แล้วสั่งเล่นคัทซีน
2. หุ่นฟางเรืองแสงทอง กล้องถอยออก
3. ไอน้ำ + ฟ้าแลบ รถคาร์โก้ก่อตัวจากแสงข้างตัวผู้เล่น (โมเดลสำเนาจาก `Car_Cargo` บนเกาะ 249 ชิ้น Part ล้วน
   → `ReplicatedStorage.WOLD_Cutscene.CargoTruck` ในเพลสหลัก · **เห็นคนเดียว** สร้างฝั่งไคลเอนต์)
4. จอมืด "คุณก้าวขึ้นรถ…"
5. รถลอยขึ้นทะลุเมฆ กล้องตาม
6. แสงขาววาบ ป้าย **"เกาะลอยฟ้าแห่งความฝัน"** / "ของขวัญจากออฟาเรียน · 30 วัน"
7. จอขาวค้าง (TeleportGui) → เซิร์ฟ `FarmRegistry.GetOrCreate(userId)` + `TeleportToPrivateServer` ไปเกาะของตัวเอง
- ข้าม = ไปข้อ 7 ทันที · วาปไม่สำเร็จ = คืนจอ + "เข้าเกาะได้จากล็อบบี้ แท็บฟาร์มมิ่ง" (VIP ได้ไปแล้ว ไม่มีอะไรหาย)
- ตรึงตัวระหว่างคัทซีนแบบเดียวกับคัทซีนแรก (`InCutscene` + เพดานเวลา) · วาปเกิดครั้งเดียวต่อบัญชี (ปุ่มรับพรมีครั้งเดียว)
- **ถึงเกาะ** (สคริปต์ฝั่งเกาะ): `Story.skyWelcome == true` → ป้ายชื่อเกาะกลางจอ + บทพูดออฟาเรียน 2 บรรทัด → ล้างธง
  · เข้าจากล็อบบี้ก่อนดูคัทซีน (ผ่านล็อบบี้เอง) ก็ได้ป้ายต้อนรับเหมือนกัน เพราะผูกกับธง ไม่ใช่กับการวาป

## ส่วนที่ 4 — บทถัดไปแบบล็อก

- `StoryConfig.Chapters` ต่อท้าย `{ id = "saltmere", locked = true, name = "เส้นทางสู่ซอลต์เมียร์",
  goal = "หาคำแนะนำจากเจ้าของฟาร์มเพื่อเดินทางไปยังซอลต์เมียร์" }` — ไม่มีขั้น ไม่มี NPC
- จบบทไลราแล้ว แถวทองนี้โผล่แบบ `locked` (จาง + 🔒) จิ้ม = "เควสนี้ยังไม่เปิด" · วันที่ทำบท 2 จริง แค่ถอด `locked` แล้วใส่ขั้น
- `Story.server` ต้องไม่เริ่ม/ไม่นับบทที่ `locked` (ห้ามสร้างความคืบหน้า ห้ามเล่นบทพูด)

## บทพูด (ร่าง — ผู้ใช้ยังไม่ได้ตรวจคำ)

**ออฟาเรียน** (`StoryConfig.Npcs.Oforian` สีทองอ่อน)

- ทักทาย (ไม่มีเควสค้าง): "ทุ่งนายังเขียวดีอยู่… เจ้าเองก็เติบโตต่อไปนะ"
- `side:newcomer`
  1. "ข้าคือออฟาเรียน ผู้เฝ้าทุ่งนาแห่งอาร์ตูร์มาตั้งแต่ก่อนเมืองนี้จะมีเครื่องจักรสักตัว"
  2. "ผู้มาใหม่ทุกคนที่ผ่านหน้าข้าไป ข้าจะมอบพรเล็กๆ ติดตัวไว้เสมอ"
  3. "รับม้วนพรแห่งฤดูกาลนี้ไป — ทุกครั้งที่เจ้าเติบโต มันจะตอบแทนเจ้า" → ได้พาสพรีเมียม
- `side:sky`
  1. "ข้าเฝ้ามองเจ้ามาตลอด ตั้งแต่วันแรกที่เจ้าหยิบจอบขึ้นมา"
  2. "ห้าก้าวแห่งการเติบโต… น้อยคนนักจะเดินมาได้ไกลขนาดนี้โดยไม่หยุด"
  3. "เหนือเมฆขึ้นไปมีเกาะที่เหล่าเทพใช้พักผ่อน — เกาะลอยฟ้าแห่งความฝัน"
  4. "ข้าจะมอบสิทธิ์ให้เจ้าครอบครองมันสามสิบวัน ปลูก เลี้ยง สร้างมันตามใจเจ้า" → ปุ่ม **"รับพร"**
- `side:travel`
  1. "เจ้าช่วยไลราไขความลับของวงเวทได้แล้ว… ข่าวไปถึงหูข้าเร็วกว่าลมเสียอีก"
  2. "การเดินทางของเจ้าเพิ่งเริ่ม รับนี่ไว้เป็นเสบียง — เพชรจากใต้รากทุ่งนาของข้า" → 150 เพชร
- `side:friends`
  1. "ข้าเห็นว่าเจ้าไม่ได้เดินทางคนเดียวอีกแล้ว"
  2. "มิตรภาพเป็นสิ่งที่แม้แต่เทพก็สร้างเองไม่ได้ ข้าจึงอยากให้มันมีแสงให้คนอื่นเห็น"
  3. "รับแสงนี้ไป ให้มันห้อมล้อมเจ้าทุกที่ที่เจ้าไป" → ออร่าสุ่ม
