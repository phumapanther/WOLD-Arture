# ความสำเร็จ + ฉายาเรืองแสงเหนือหัว — ดีไซน์

วันที่ 2026-09-25 · ระบบที่ 4 จาก 4 ของชุด "MMO เพิ่มเติม" · ผู้ใช้สั่ง "ทำเลย" (ไม่รออนุมัติสเปกแยก)

## สิ่งที่ผู้ใช้กำหนด

| ข้อ | ค่า |
|---|---|
| ที่อยู่ | **เมนูเดียวกับสมุดสะสม** (หินเวท P → สมุดสะสม) แท็บที่สาม "ความสำเร็จ" |
| ฉายาเหนือหัว | **เรืองแสง** · ผู้เล่น **เลือกเองจากที่ปลดแล้ว** (หรือไม่ใส่) |
| VIP | ได้ฉายา **"VIP" สีทอง** ให้เลือกใช้ ตลอดที่ VIP ยังไม่หมด (หมดแล้วถอดเอง) |
| หัวแดง | ฉายา **"หัวแดง"** ขึ้นเองตอนติดสถานะหัวแดง **ถอดไม่ได้จนหมดเวลา** แล้วกลับเป็นฉายาที่เลือกไว้ |
| นับจาก | ฆ่ามอน/ตกปลา (สมุดสะสมเดิม) · เลเวล/ตีบวก · PVP/บอสโลก |
| รางวัล | **ฉายา + เพชร** |

## ความสำเร็จ (ผมตั้งชื่อ/เป้า/เพชร — แก้ได้ที่ `AchievementConfig` ไฟล์เดียว)

| กลุ่ม | ฉายา | เงื่อนไข | เพชร |
|---|---|---|---|
| มอน | นักล่ามือใหม่ / นักล่า / เพชฌฆาตแห่งอาร์ทัวร์ | ฆ่ามอนรวม 100 / 1,000 / 10,000 | 10 / 30 / 100 |
| มอน | ผู้รู้จักสัตว์ประหลาด | ฆ่ามอนครบ 10 ชนิด | 30 |
| ปลา | ชาวประมง / เจ้าแห่งคันเบ็ด | ตกปลารวม 50 / 500 | 10 / 30 |
| ปลา | นักสะสมปลา | ตกปลาครบ 10 ชนิด | 30 |
| เลเวล | นักผจญภัย / ผู้กล้า / วีรชน / ตำนาน | เลเวล 10 / 30 / 50 / 100 | 10 / 30 / 50 / 150 |
| ตีบวก | ช่างฝีมือ / เทพแห่งเตาหลอม | ตีบวกสำเร็จถึง +5 / +10 | 20 / 150 |
| PVP | นักสู้สนาม / แชมป์สนาม | ชนะแมตช์ 1 / 10 ครั้ง | 10 / 50 |
| PVP | เอซ | ทำ ACE 1 ครั้ง | 50 |
| PVP | นักฆ่าสนาม | คิลในสนามรวม 100 | 50 |
| บอสโลก | ผู้ท้าบอส / ผู้โค่นยักษ์ / ดาบสุดท้าย | ติดอันดับรางวัล / อันดับ 1 / ไม้สุดท้ายที่ฆ่าบอส | 20 / 100 / 50 |

แต่ละอันมีสี (ธรรมดา ฟ้า · หายาก ม่วง · ตำนาน ทอง) ใช้ทั้งในหน้าจอและบนหัว

## ข้อมูล
`profile.Data.Achievements = { stats = {...}, unlocked = { [id] = os.time() }, title = id|nil, seen = { messageId,... } }`
- สถิติที่ **อ่านสด** ไม่เก็บซ้ำ: ฆ่ามอนรวม/ชนิด · ตกปลารวม/ชนิด (จาก `Data.Collection`) · เลเวล (`Progression.GetLevel`)
- สถิติที่ **จดเอง** ใน `stats`: `maxEnhance` (Crafting ตอนตีบวกสำเร็จ) · `pvpWins` `pvpAces` `pvpKills` · `bossJoins` `bossTop1` `bossLastHits`
- PVP กับบอสโลก **ส่งผ่าน ProfileStore:MessageAsync** (`kind = "stats"`) — เซิร์ฟสนามเขียนโปรไฟล์ไม่ได้ และคนที่ออกไปก่อนบอสจบก็ต้องได้นับ · ตัวรับใน `PlayerProfile` ตัดซ้ำด้วย id (เก็บ 20 ตัวล่าสุด)

## องค์ประกอบ
- `ReplicatedStorage/AchievementConfig.lua` — รายการ + สี + ฉายาพิเศษ (VIP / หัวแดง) + `IsDone(def, value)`
- `ServerScriptService/Achievements.lua` — อ่านสถิติ · `Record` · `AddStatsData` (ตัวรับข้อความ) · `Snapshot` · `Check` (ปลด + ให้เพชร) · `DisplayTitle` (หัวแดง > ที่เลือกไว้ถ้ายังใช้ได้)
- `ServerScriptService/Achievements.server.lua` — ลูป 2 วิ: ปลดของใหม่ → เพชร + แจ้ง · ประกาศฉายาบนตัวผู้เล่น (`WOLD_Title` / `WOLD_TitleColor`) · remote `RequestTitle(id|"")`
- `StarterPlayerScripts/TitleTagController.client.lua` — ลูป 0.5 วิวาดป้ายเหนือหัวทุกคนที่มี `WOLD_Title` (BillboardGui ขนาดเป็นสตัด · แสงเต้นช้าๆ) · **โชว์แค่ฉายา ไม่มีชื่อ/เลเวล** (กติกาเดิมของเกม: หัวคนแปลกหน้าไม่บอกว่าเป็นใคร)
- `SocialGui` แท็บ "ความสำเร็จ": แถวละอัน (ฉายาสี · เงื่อนไข · ความคืบหน้า · เพชร · ปุ่ม "ใช้ฉายา"/"กำลังใช้") + แถว "ไม่ใช้ฉายา" + ฉายา VIP ถ้ามี · ข้อมูลมากับ `CollectionUpdate` เดิม (`snapshot.achievements`)
- สนาม PVP ไม่รันระบบนี้ (ไม่มีโปรไฟล์) — `ArenaRewards` แค่ส่งข้อความสถิติ

## นอกขอบเขต
- ความสำเร็จจากคราฟ/เก็บเกี่ยว (ผู้ใช้ไม่เลือก) · ฉายาในสนาม PVP · ประกาศข้ามเซิร์ฟตอนปลด (ระบบที่ 2)
