# WOLD Arture v1.5 → v2 — แผนระยะยาว (ผู้ใช้อนุมัติทีละข้อ 2026-09-26)

ทุกอย่างในไฟล์นี้คือ **เวอร์ชัน 1.5** — `GameVersion` ขึ้น 1.5 ตั้งแต่วันเริ่มทำ (tag `rolplayV_1.5`)
เสร็จครบทุกเฟสแล้ว → เทสหาบั๊ก/ช่องโหว่ + ปรับดีไซน์ + เช็คเงื่อนไขทั้งหมด → ขึ้น **เวอร์ชัน 2** เพื่อโปรโมทเต็มตัว

**ลำดับ (ผู้ใช้เลือก):** เฟส 0 บั๊ก → 1 UI PVP → 2 เกาะ (2a ร้าน → 2b ขอบทอง/บัฟ/กระเป๋า → 2c เลเวลฟาร์ม+รถ+คราฟ →
2d สัตว์เลี้ยง → 2e บ้าน) → 3 แร็งก์+แมพ → 4 เนื้อเรื่อง → 5 ดันเจี้ยน → 6 QA ขึ้น v2

**จังหวะ (ผู้ใช้เลือก):** ทำทีละเฟส · ทุกเฟส: เทสใน Edit + ดันเข้าเพลสที่เกี่ยว (hash ตรง 0) + commit → บอกสิ่งที่ต้องเทสในเกม
→ **ผู้ใช้เทสผ่านก่อนค่อยเริ่มเฟสถัดไป** · ผู้ใช้เทสในเกมเอง (ไม่กด Play แทน)
แต่ละเฟสเขียนแผนลงมือ (writing-plans) ของตัวเองตอนเริ่มเฟส โดยอิงไฟล์นี้เป็นสเปก

**ระหว่าง v1.5:** ผู้ใช้ประกาศผู้เล่นว่า "ตอนนี้ปลดทุกอย่างให้อยู่ ระบบล็อกจะตามมาทีหลัง" — ระบบล็อกสองตัว
(เลเวลฟาร์ม 2c · เนื้อเรื่องล็อกบอร์ด 4) เข้ามาตามลำดับเฟส จนกว่าจะถึงเฟสนั้นทุกอย่างเปิดเหมือนเดิม

## เฟส 2b · ของขอบทอง + บัฟ 3 สี + กระเป๋า VIP 36 ช่อง
**ของขอบทอง**
- ได้เฉพาะบนเกาะ: ผลผลิตสัตว์คอก · ผลผลิตแปลงผัก (รวมกิ่งเวทมนตร์) · แร่ทุกชนิด **ยกเว้นถ่านหิน/หิน** —
  ไม้ สมุนไพร ปลา เมล็ด หนอน ไม่มีขอบทอง
- ทอยต่อการเก็บ 1 ครั้ง ได้ขอบทองสูงสุด **1 ชิ้น** ที่เหลือธรรมดา · โอกาสปกติ **10%** · ติดแสงทอง **40%** · ติดแสงแดง **100%**
- แสงฟ้า (ของ ×2) **ไม่คูณ** ขอบทอง
- แยกชิ้น ไม่สแตค (meta `gold = true` — กติกา meta ไม่สแตคมีอยู่แล้ว `Inventory.lua:162,169,212,217`) · เข้า**กระเป๋า VIP**
  (`rangeFor` ต้องรับ meta ด้วย ตอนนี้ตัดสินจาก id อย่างเดียว `Inventory.lua:85-90`)
- ขาย**บนเกาะเท่านั้น** ราคา **3× ราคาตลาด ณ ตอนนั้น** · **ขายทีละชิ้น** ปุ่มขายทั้งหมดข้ามขอบทอง · ร้านเกมหลัก + `TownBuyers` ไม่รับ
  (`Shop.server buyPrice :88-113` + sell-all `:333-349` · `TownBuyers priceFor :61-78`)
- **ติดตัวได้แต่โอนไม่ได้**: ห้ามฝากคลัง (รวมลังบนเกาะ = คลังเดียวกัน) ส่งเมล เทรด ให้ของ คลังแคลน คลังเมือง ตู้บนเกาะ
  (`IsMailable/IsStorable` รับแค่ id `ItemCatalog.lua:815,857` → ต้องรับ meta · Trading `:137` · ClassActions give `:371` ·
  Clans `:583,625` · TownVault `:174,212` · StorageChests `:183,210` · ท้ายรถข้าม meta อยู่แล้ว)
- **ห้ามเป็นวัตถุดิบ/ส่งเควส/ตีบวก** — ตอนนี้ทุกตัวนับ/หักตาม id และ `RemoveById` เดินจากท้ายกระเป๋า = กินขอบทองก่อน:
  `Inventory CountOf :105 · RemoveById :125 · FindSlotById :558` · `Crafting countMaterial :52 · takeMaterial :67` (+ enhance `:597,609`) ·
  `Quests progressOf :146 · :360` · `IslandAccess.Count/Revoke` — ต้องข้ามช่อง `meta.gold` ทุกจุด (เทสจับทุกทาง)
- ส่งออกได้ (เฟส 2c มีใบสั่งขอบทองโดยเฉพาะ)

**บัฟแสง** (`IslandConfig.Glow` + `RollGlow` ต้องรับบริบทว่าของชิ้นนั้นมีขอบทองได้ไหม)
- โอกาส: **ฟ้า 7% · ทอง 2.5% · แดง 0.5%** (รวม 10% เท่าเดิม)
- ฟ้า = ของ ×2 · ทอง = EXP ×2 + ขอบทอง 40% · **แดง = ขอบทองแน่นอน + ของ ×2 + EXP ×2**
- **แดงขึ้นเฉพาะของที่มีขอบทองได้** (ต้นไม้/พุ่มมีแค่ฟ้า/ทอง)
- จุดที่ต้องแก้: สีแดงใน `Glow.colors` · ข้อความ `IslandPlots:215-218` (ตอนนี้ไม่ใช่ทอง = ฟ้า) · ออร่า `IslandBadgeController:132`

## เฟส 2c · เลเวลฟาร์ม + รถส่งออก + คราฟขั้นสูง (ชุดเดียวกัน — วงจร เก็บ → คราฟ → ส่งออก → เลเวล → ปลด)
**เลเวลฟาร์ม**
- EXP ฟาร์มได้จาก**การส่งออกเท่านั้น** · ไม่มีวันลด (คนละตัวกับเลเวลตัวละครที่รีเซ็ตตอนตาย) · เพิ่มเลเวลได้เรื่อยๆ ตามของใหม่
- ปลดของจากถูกไปแพง: สินค้าในร้าน · สัตว์คอก · โซนแร่ · สัตว์เลี้ยง · บ้าน (+เพดานจำนวนบ้าน) · เครื่องคราฟ/สูตร · บัฟแสง
- **ของที่ผู้เล่นมีอยู่แล้วใช้ต่อได้ทั้งหมด** ล็อกแค่การซื้อใหม่ · ดูเลเวล/ของที่จะปลดได้ที่**ตัวรถส่งออก**
- **เกาะใหม่:** แปลงผัก 9 + เมล็ด **ไม่มีบ้าน** (ตอนนี้แจกบ้านหินฟรี `IslandConfig:24-29` · `IslandBuild:469-479`)
- เก็บที่ `profile.Data.Island.farm` (Data.Island สร้างแบบ lazy ไม่อยู่ในเทมเพลต)

**รถส่งออก** — โมเดล **`Car_Cargo`** ที่มีอยู่แล้วในเพลสฟาร์มมิ่ง (**ตรวจก่อนเริ่มเฟส**: อยู่ที่ไหน กี่คัน ชื่อเป๊ะ)
- กด E ที่รถ → หน้าต่าง: เลเวล/EXP · รายการปลด · **ใบสั่งซื้อ 3 ใบ** (สุ่มจากของที่ปลดแล้ว)
- ส่งได้**ทีละใบ** · ใช้เวลา **30 นาที** รถ**จอดอยู่ที่เดิม**มีแถบเวลา · **นับต่อตอนออฟไลน์** (os.time ในโปรไฟล์)
- ส่งเสร็จ → **EXP ฟาร์ม + เหรียญ + เพชร** → ใบใหม่สุ่มมาแทน
- **เพชร:** 3 ใบแรกของวันได้แน่นอน · ใบถัดไป 50% · ใบละ 1-2 · **เพดาน ใบละ 2 · วันละ 5 · เดือนละ 150** (วันพลิกเที่ยงคืนไทย `QuestConfig.DayNumber`)
- บางใบ**ขอของขอบทองโดยเฉพาะ** รางวัลสูง · สุ่มใบใหม่ได้**ฟรีวันละ 1 ครั้ง**

**คราฟขั้นสูง** — เครื่องละงาน วางหลายเครื่องทำขนานได้ · ขั้นสูงสุด **2 ชม.** · ของขั้นสุดท้าย**ส่งออกอย่างเดียว** (ไม่กิน ไม่ใช่ของใช้)
- **เครื่องทอผ้า**: ฝ้าย (**พืชใหม่**) → ด้าย → ผ้าทอ · ขนแกะ (จากคอก) → ไหมพรม → ผ้าขนสัตว์ · ต่อยอดเป็นผ้าขั้นสูง
- **เตาเบเกอรี่**: ข้าว → แป้ง → แป้งโด → ขนมปังพิเศษ/เค้ก/พาย
- **โต๊ะคราฟของเหล็ก** (ไม่มี NPC ไม่มีของตกแต่งเป็นคน): แร่**ทุกชนิด** → แท่ง → ตะปู/บานพับ/เฟือง/ชิ้นส่วน → ของขั้นสูง
- ต่อเครื่อง: ItemCatalog (ของวาง + วัตถุดิบระหว่างทางทุกตัว) · ต้นแบบ mapgen/90 · `IslandBuild FUNCTIONAL :15-19` ·
  `CraftStations STATIONS :35-39` · แท็บ+สูตร (**ต่อท้ายเท่านั้น** เลขสูตรคือสัญญากับไคลเอนต์) · ท่า `CraftPoseController` · หมวดร้าน
- โมเดลเครื่องใหม่ปั้นที่โรงงาน WOLD-Models
