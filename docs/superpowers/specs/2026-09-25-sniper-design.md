## 1. สไนเปอร์

### ข้อมูล
- `ItemCatalog.Sniper` — `kind = "weapon"` `weight = 6` `stackSize = 1` `damage = 0` (ไม่ใช้ ดาเมจคิดเป็นสัดส่วน) `maxDurability = 120`
- `CombatConfig.Weapons.Sniper` — ท่ายืน = `Staff_Idle` · ท่ายิงหนึ่งท่า `windup = 0.5` `recovery = 0.6`
  `projectile = { kind = "hitscan", length = 400, ... }` · `manaCost = 1` · `scope = true` · `quickDraw = true`
  · `pierceFraction = 0.5` (ใส่คน) · `mobDamage = 150` (ใส่มอนเกมหลัก)
- `CombatConfig.Sounds.Sniper.cast` = เสียงยิงของผู้ใช้
- `CraftConfig` สูตรที่ช่างตีเหล็ก แท็บอาวุธ (ผมตั้ง ทรงเดียวกับดาบใหญ่/โล่):
  IronOre 30 · GoldOre 10 · Crystal 5 · Coal 20 · GearSpare 10 · Blueprint 5 · Chemical 5 · สำเร็จ 25% · ค่าจ้าง 25,000

### ยิงยังไง (ฝั่งเซิร์ฟเวอร์ตัดสินทุกอย่าง)
1. คลิก → `RequestAttack(aim)` · **`quickDraw` = ไม่ต้องคลิกแรกยกการ์ดก่อน** (ปืน/ดาบยังต้องเหมือนเดิม)
2. เซิร์ฟเวอร์หักมานา 1 (`Vitals.TrySpendMana`) ไม่พอ → แจ้ง "มานาไม่พอ" แล้วจบ ไม่เริ่มท่า
3. เริ่ม windup 0.5 วิ ส่ง `CombatStateChanged(..., windup)` ตามเดิม → ไคลเอนต์เจ้าของเปิดสโคป + แถบ
4. **ระหว่าง 0.5 วิผู้เล่นเล็งต่อได้**: ไคลเอนต์ส่ง `Remotes.RequestAimUpdate(aim)` ก่อนครบเวลา เซิร์ฟเวอร์เก็บเป็น
   `state.latestAim` (รับเฉพาะตอนมี windup ค้าง และตรวจแบบเดียวกับ `aimDirection` — ทิศทางเท่านั้น ไม่ได้ทำให้ยิงไกลขึ้น/เร็วขึ้น)
5. ครบ 0.5 วิ ยิงด้วย `latestAim` (ไม่มีก็ใช้ aim ตอนคลิก) — **hitscan**: raycast ครั้งเดียวจากปากกระบอกไปตามทิศ 400 สตัด
   ชนอะไรก่อนโดนสิ่งนั้น (ไม่ใช่วงกว้าง 8 สตัดแบบกระสุนอื่น — สไนต้องเล็งจริง)
   · มีเส้นกระสุนสว่างวาบ 0.1 วิ ให้คนอื่นเห็น
6. โดนคน → `Vitals.ApplyDamage(other, maxHp × 0.5, "combat", { pierce = true })` — `pierce` ข้ามการหักเกราะ
   (บัพ "เลือดไม่ลด"/อมตะยังกันได้ตามเดิม) · โดนมอน → 150 · ในสนาม ดูข้อ 4

### จอสโคป (ไคลเอนต์ เจ้าของเท่านั้น)
- `UI/ScopeGui.lua` + ต่อสายใน `AimController`: ตอนเริ่ม windup ของสไน → กล้อง FOV 70 → 20 · ซ่อนเป้าเล็งปกติ
  · วาดตามภาพ: พื้นเทาทึบรอบนอก วงกลมใส่ขอบดำกลางจอ (ขนาดตามด้านสั้นของจอ) กากบาทเทาสี่ขีดเว้นกลาง + ตรงกลาง
  · แถบ 0.5 วิอยู่ใต้วงกลม · ยิงแล้วค้างอีก 0.15 วิแล้วซูมออก
- วาดด้วย Frame/UICorner/UIStroke ล้วน ไม่มีรูป (ไม่ต้องอัปโหลดอะไร)

### โมเดล + ท่าถือ
- `WeaponPrefabs.Builders.Sniper` ปั้นด้วยโค้ด: ลำกล้องยาว ตัวปืนไม้ กล้องเล็งบนหลัง แม็กกาซีน ขาทราย ·
  ผังเดียวกับปืนพก (ปลายกระบอกที่จุดกำเนิด ด้ามไป +Y) เพื่อให้ `GRIP`/สกินใช้กติกาเดียวกัน
- `WeaponVisuals`: `ANCHOR_ALWAYS.Sniper = "UpperTorso"` + ระยะวางกลางอก หันลำกล้องไปข้างหน้า (-Z ของลำตัว)
  — ติดอกตลอด ไม่ใช่แค่ตอนยิง (ผู้ใช้สั่ง "ปืนอยู่กลางอก") · ท่ายืนของคทาทำให้สองมือมาอยู่หน้าอกพอดี

## 2. แถบดีเลย์ทุกท่า
- ตอนนี้เซิร์ฟเวอร์ส่ง windup เฉพาะท่ายิง (`attack.projectile and attack.windup`) และแถบวาดอยู่ใน GUI เล็งซึ่งเปิดเฉพาะอาวุธระยะไกล
- เปลี่ยนเป็น **ส่ง windup ทุกท่าที่ `windup >= CombatConfig.ChargeBarMinSeconds` (0.3)** → ดาบใหญ่ 1.2 · ปืน 0.35 · ธนู 0.4 · สไน 0.5
  (ดาบ/หมัด/คทา/สมุด 0.1–0.24 แถบจะแวบแล้วหาย ไม่ส่ง)
- แถบย้ายไปอยู่ ScreenGui ของมันเองที่เปิดตลอด (ไม่ผูกกับ GUI เล็ง) ตำแหน่งกลางจอค่อนล่าง
- เกมหลักและ PVP ใช้โค้ดเดียวกัน (`PlayerCombat` รันทั้งสองเพลส) ไม่ต้องแยก

## 3. ร้าน B ในโหมด PVP
- `ArenaConfig.Shop` เพิ่มฟิลด์ `size = "small" | "medium" | "large"` ให้อาวุธ + แถว `Sniper` (ranged, large, 3,000)
  · ดาบใหญ่ 1,500 → **3,000** · ราคาอื่นเหมือนเดิม
- `ArenaShopGui` เรียงการ์ดในแถวอาวุธตาม เล็ก → กลาง → ใหญ่ และมีป้ายขนาดบนการ์ด (เล็ก/กลาง/ใหญ่ คนละสี)
- สไนในสนามใช้มานาเหมือนเกมหลัก — มานาในสนามเริ่มที่ 0 ได้จากขวดน้ำ (3 ขวด/รอบ) = **ยิงได้ 3 นัดต่อรอบ** (ตั้งใจ เป็นอาวุธหนัก)

## 4. ยิงหัว (PVP เท่านั้น)
- เกมรู้ว่ากระสุนชน **ชิ้นไหน** ของร่างเฉพาะกระสุนที่ raycast (กระสุนบิน · ลำแสงคทา · สไน) — ท่าฟันระยะประชิดใช้วงกลมรอบตัว
  แยกหัว/ตัวไม่ได้ **จึงมีผลกับอาวุธระยะไกลเท่านั้น**
- หัว = ชิ้นชื่อ `Head` หรือชิ้นใน Accessory ที่เชื่อมกับ `Head` (หมวก/ผม) ของตัวละครหรือบอท
- `ArenaConfig.HeadshotMultiplier = 2` (ผมตั้ง "แรงกว่ามาก") · **สไนโดนหัว = ดาเมจเท่าเลือดที่เหลือทั้งหมด (ตายทันที)**
  สไนโดนตัว = 50% ของเลือดเต็ม
- บอทในสนามโดนสไน = 50% ของเลือดเต็ม **ของบอท** (บอทคือผู้เล่นฝั่งตรงข้าม ไม่ใช่มอน 150)
- เกมหลักไม่มีการคูณหัว (ผู้ใช้สั่งเฉพาะ PVP)
- ไคลเอนต์คนยิงเห็นเลขดาเมจสีแดง + คำว่า "HEADSHOT" บนการ์ดดาเมจเดิม

## 5. แบนเนอร์คิล (PVP เท่านั้น)
- `ArenaMatch.killCredit` รู้อยู่แล้วว่าใครเก็บ → ส่ง `Remotes.ArenaKillBanner` ถึง **คนเก็บคนเดียว** พร้อม `{ victim, kind, streak }`
- ข้อความ: คิลธรรมดา "ELIMINATED — <ชื่อ>" · คิลแรกของรอบ (ทั้งสนาม) **FIRST BLOOD** · คิลที่สองติดกันใน 10 วิ **DOUBLE KILL** ·
  ที่สาม **TRIPLE KILL** (3v3 ได้มากสุดสาม) — หน้าต่าง `ArenaConfig.MultiKillSeconds = 10`
- UI `UI/KillBannerGui.lua`: ป้ายกลางบนจอ ตัวหนังสือใหญ่ขอบทอง เด้งขยาย (TweenSize/UIScale) แล้วจางออกใน 2 วิ · ต่อคิวถ้ามาติดกัน
- เสียง `107279082816485` ทุกคิล · **เสียงพากย์ FIRST BLOOD/DOUBLE/TRIPLE**: ลองค้น Creator Store ตอนลงมือ
  ถ้าเจอเสียงที่ใช้ได้ใส่ id ใน `ArenaConfig.KillSounds` · ไม่เจอ = ใช้เสียงเดียวกันแต่ `PlaybackSpeed` สูงขึ้นตามระดับ (1.0 / 1.1 / 1.2 / 1.3)
  ช่องใส่ id รอไว้ เปลี่ยนทีหลังไม่ต้องแตะโค้ด

## กรณีผิดพลาด
- ยิงสไนตอนมานา 0 → ไม่เริ่มท่า ไม่เสียความคงทน ขึ้นเตือนครั้งเดียว
- ตาย/ล้ม/ถอดอาวุธระหว่าง windup → ไม่ยิง (ตรวจตอนครบเวลาว่ายังถือสไนและยังไม่ล้ม) · มานาที่หักไปแล้วไม่คืน
- `RequestAimUpdate` มาตอนไม่มี windup ค้าง / ค่าแปลก (NaN, ไม่ใช่ Vector3) → ทิ้ง
- จอสโคปค้าง: ปิดเสมอเมื่อ ครบเวลา+0.15 · ตัวละครตาย · ถอดอาวุธ
