# ระบบหลายภาษา (ไทย · English · 简体中文 · 日本語) — สเปก

ผู้ใช้อนุมัติแบบในแชท 2026-10-03 · ทำเป็นเฟส · **เฟส 1 = ส่วนที่เห็นบ่อย**

## เป้าหมาย
ผู้เล่นทุกคนเห็นเกมในภาษาของตัวเอง: ครั้งแรกอ่านจากภาษาที่ตั้งในไอดี Roblox และเปลี่ยนเองได้ที่หน้าตั้งค่าของหินเวทสื่อสาร
ภาษาต้นฉบับยังเป็นไทย (โค้ดยังเขียนไทยเหมือนเดิม) · ข้อความที่ยังไม่มีคำแปลขึ้นไทยเดิม ไม่พัง

## การตัดสินใจของผู้ใช้
- คำแปล **Claude แปลเก็บในรีโป** (ไม่ใช้ Automatic Translation ของ Roblox) — โปรเจ็คแปลของผู้ใช้มาเกลาทีหลังได้
- จีน = **จีนตัวย่อ** อย่างเดียว (zh-tw/zh-hk ก็ได้ตัวย่อ)
- ภาษาไอดีที่ไม่ใช่ ไทย/อังกฤษ/จีน/ญี่ปุ่น → **อังกฤษ**
- แบ่งเฟส เฟส 1 ส่วนที่เห็นบ่อย

## โครงสร้าง

### กุญแจ = ประโยคไทยต้นฉบับ
`src/ReplicatedStorage/Locale/init.lua` (โมดูล `Locale`) — ใช้ได้ทั้งเซิร์ฟเวอร์และไคลเอนต์
- `Locale.T(lang, thai, ...)` → คำแปลของ `thai` ในภาษา `lang` แล้ว `string.format(..., ...)` ถ้ามีอาร์กิวเมนต์
  ไม่มีคำแปล / lang = "th" → ใช้ `thai` เอง · format พัง (pcall) → คืนไทยที่ format แล้ว
- `Locale.L(thai, ...)` (ไคลเอนต์) = `T(ภาษาของผู้เล่นในเครื่อง, ...)`
- `Locale.For(player, thai, ...)` (เซิร์ฟเวอร์) = `T(ภาษาของคนนั้น, ...)`
- `Locale.FromLocaleId(localeId)` กติกาล้วน: `th*`→th · `en*`→en · `zh*`→zh · `ja*`→ja · อื่น/ว่าง→en
- `Locale.Languages` = รายการ `{ id, label }` สี่ภาษา ป้ายเขียนด้วยภาษานั้นเอง (ไทย · English · 简体中文 · 日本語)
- ตารางคำแปล `Locale/en.lua` `Locale/zh.lua` `Locale/ja.lua` = `{ ["ประโยคไทย"] = "คำแปล" }` ล้วน
  ตัวคั่นรูปแบบ (`%s` `%d` `%.1f` …) ต้องครบเท่าต้นฉบับและเรียงลำดับเดิม

### ภาษาของแต่ละคน
- ที่เก็บ: DataStore แยก `WOLD_Lang_v1` คีย์ `u_<userId>` = `"th"|"en"|"zh"|"ja"` (ทรงเดียวกับ `PvpRankStore`)
  เหตุผล: ล็อบบี้/สนามเปิดเซสชันโปรไฟล์ไม่ได้ แต่ต้องรู้ภาษา
- `LanguagePublisher.server.lua` (ทุกเพลสรวมล็อบบี้/สนาม): ผู้เล่นเข้า → อ่านที่เก็บ · ไม่มี = `FromLocaleId(player.LocaleId)`
  (ไม่เขียนลงที่เก็บจนกว่าผู้เล่นเลือกเอง) → ตั้งแอตทริบิวต์ `WOLD_Lang` บนตัว Player ·
  `Remotes.SetLanguage(lang)` ตรวจว่าอยู่ใน `Languages` แล้วเขียนที่เก็บ + ตั้งแอตทริบิวต์ใหม่
- ก่อนแอตทริบิวต์มาถึง ไคลเอนต์ใช้ `FromLocaleId(LocalPlayer.LocaleId)` ไปก่อน (ไม่รอ)

### หน้าตั้งค่าหินเวท
แถว "ภาษา / Language" ปุ่มสี่ปุ่ม ปุ่มที่เลือกอยู่ไฮไลต์ · ใช้ได้ในล็อบบี้ด้วย (หน้าตั้งค่าใช้ได้อยู่แล้ว) ·
ใต้ปุ่มบอก "บางส่วนจะเปลี่ยนเมื่อเข้าเกมใหม่" (แปลแล้ว)

### เปลี่ยนภาษากลางเกม
ไม่รื้อหน้าต่างให้วาดใหม่: ของที่วาดทุกครั้งที่เปิด/ข้อความเด้งใหม่เปลี่ยนทันที · ป้ายที่สร้างครั้งเดียวตอนบูตเปลี่ยนหลังเข้าเกมใหม่

### ข้อความจากเซิร์ฟเวอร์
เซิร์ฟส่งไทยสำเร็จรูปเหมือนเดิม ไคลเอนต์แปลตอนแสดงด้วย `Locale.Translate` (จับคู่แม่แบบ `%s/%d/%.1f` ย้อนกลับ + แปลชื่อที่จับได้) —
ไม่ต้องแก้ทุกจุดที่ส่งข้อความ และเสียงข้อความเด้งที่ดูคำไทยยังทำงาน · แม่แบบต้องอยู่ในตารางคำแปล (แก้ตอนวางแผน 2026-10-05 · เดิมแปลที่เซิร์ฟด้วย `Locale.For`)
**ไม่แปล:** ชื่อผู้เล่น ชื่อแคลน ข้อความที่ผู้เล่นพิมพ์ (เมล บอร์ด นกพิราบ) และคำสั่งแอดมิน

### ชื่อไอเทม
`ItemCatalog.DisplayName(id, meta, lang)` แปลชื่อฐานที่เดียว (`lang` ไม่ส่ง = ไคลเอนต์ใช้ภาษาในเครื่อง · เซิร์ฟใช้ไทย)
ทุกหน้าต่างที่เรียก `DisplayName` ได้คำแปลเอง · คำอธิบายไอเทมแปลผ่าน `L` ที่จุดแสดง

## เทส (offline)
- `locale_test`: `FromLocaleId` ครบทุกกรณี · `T` ไม่มีคำแปล = ไทย · format ถูก · format พัง = ไม่ error
- `locale_coverage_test`: ทุกคำแปลมีตัวคั่น `%…` ตรงต้นฉบับ · ทุก `L(`/`For(`/`T(` ที่เป็นสตริงคงที่ในไฟล์ของเฟสที่ทำแล้ว
  มีคำแปลครบสามภาษา · ไม่มีคำแปลที่ไม่มีต้นฉบับอยู่ในโค้ด (ค้าง)

## ความเสี่ยง (ต้องดูในเกม)
- อังกฤษยาวกว่าไทย → ปุ่ม/ป้ายล้น ต้องเปิดดูทีละหน้า (ใช้ `tools/ui-audit` ช่วยได้)
- ฟอนต์จีน/ญี่ปุ่นต้องไม่ขึ้นกล่องเปล่า (Roblox มีฟอนต์สำรอง CJK แต่ต้องยืนยันในเกม)
- ข้อความที่ประกอบด้วย `..` (ไม่ใช่ `%s`) แปลเป็นชิ้นไม่ได้ ต้องแก้เป็น format ตอนครอบ
