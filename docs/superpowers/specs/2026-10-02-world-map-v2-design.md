# แผนที่โลก v2 — วาดจากโลกจริง + หมุดอีโมจิกดนำทางได้ (เกมหลัก)

ผู้ใช้สั่ง 2026-10-02 · เลือกแล้ว: แผนที่วาดจากโลกจริง (ไม่ใช่ภาพถ่ายมุมสูง) · หมุดครบทุกหมวดเป็นอีโมจิ · แถบหมวดกดเปิด/ปิด ·
กดหมุด = นำทางทันที

## เป้าหมาย

1. แผนที่ (M / หินเวท) ชัดและเหมือนแมพจริง: ภูเขามีเงา น้ำตื้น-ลึกต่างสี ป่า หิมะ ชายหาด และ **เห็นตัวอาคารในเมือง**
2. หมุดอีโมจิทุกหมวด ตำแหน่งจากของจริงในแมพ (ย้ายของในสตูดิโอ = หมุดตาม) · กดแล้วปักหมุดนำทางทันที
3. ไม่หนักกว่าเดิมบนมือถือ (เดิมวาดพื้นเป็น Frame หลายพันอัน → รูป 4 แผ่น)

ไม่ทำ: แผนที่เกาะ/สนาม (เหมือนเดิม) · ภาพถ่ายมุมสูง · ชื่อภูมิภาค/ถนน (ถนนไม่มีจริงในแมพ)

## 1. ภาพแผนที่ (ทำครั้งเดียวตอนพัฒนา อัปเดตเมื่อแมพเปลี่ยน)

1. **วัดโลกจริง** `tools/sample-map.lua` + ตัวขับ `tools/build-map-image.js` (ทรงเดียวกับ build-map-terrain: ทีละแถบ < 100KB)
   กริด 1024×1024 (≈ 15.6 สตัด/ช่อง) ต่อช่องได้:
   - ผิวเทอร์เรน: วัสดุ + ความสูง (ชนน้ำ = น้ำ)
   - ก้นน้ำ: เรย์ข้ามน้ำ → ความลึก (ไว้ไล่สีน้ำตื้น-ลึก)
   - สิ่งก่อสร้าง: เรย์ชน Part ที่ไม่ใช่ต้นไม้/หิน/พุ่ม (`WOLD.Gather`) และไม่ใช่ของล่องหน → สีของชิ้นที่ชน (12 บิต) + ความสูง
2. **วาดภาพ** `tools/render-map.py` (PIL + numpy) → 2048×2048:
   สีตามวัสดุ (ชุดสีใหม่โทนแผนที่ RPG) · เงาภูเขาแสงจากตะวันตกเฉียงเหนือ (hillshade) · ไล่สีตามความสูง · น้ำไล่ตื้น→ลึก + เส้นขอบฝั่ง ·
   ป่ามีลายจุดต้นไม้ · หิมะ · อาคารเป็นสีหลังคาจริง + เงาตกด้านขวาล่าง · เส้นชั้นความสูงจางๆ ทุก 100 สตัด
   แล้วตัดเป็น 2×2 แผ่น แผ่นละ 1024 (Roblox ย่อรูปเกิน 1024 เอง)
3. **อัปโหลด** ผ่าน Studio (`upload_image` · บัญชีเจ้าของเพลส) → เลข image 4 ตัวใส่ `MapConfig.Tiles` · ตรวจโหลดจริงด้วย PreloadAsync
4. `MapTerrain.lua` (กริด 360) **คงไว้** — ใช้หาความสูง/กันปักหมุดกลางน้ำตอนแตะพื้นที่ว่าง เหมือนเดิม

แมพเปลี่ยนเมื่อไหร่: รัน build-map-image → render-map → อัปโหลด → แก้เลข 4 ตัว

- แถบกรอง: ปุ่มอีโมจิเรียงแนวตั้งขอบซ้ายในกรอบแผนที่ แตะ = ซ่อน/โชว์หมวดนั้น (จางเมื่อปิด) · จำในเซสชัน · เริ่มเปิดทุกหมวด
- หมุดขนาดคงที่บนจอทุกระดับซูม · ชื่อเมือง/หมู่บ้าน/แลนด์มาร์กขึ้นใต้หมุดเสมอ · หมุดย่อยขึ้นชื่อเมื่อชี้เมาส์ (คอม) และในแถบล่างเมื่อแตะ

### กดหมุด

- แตะ/คลิกหมุด = `nav:SetDestination(ตำแหน่ง, ชื่อหมุด)` ทันที → แถบล่าง "นำทาง: ร้านบาร์นาบี" · เส้นทาง + T/ปุ่ม 🚶 เดินอัตโนมัติได้ต่อ
- แตะหมุดนำทางเดิมซ้ำ = เลิกนำทาง (กติกาเดิม) · แตะพื้นว่างบนบก = ปักหมุดตรงนั้นเหมือนเดิม
- ตัดสินว่าแตะโดนหมุดด้วยกรอบหมุดบนจอ ในจุดเดียวกับที่ตัดสินการแตะพื้น (`pinAt`) — ไม่ผูก Activated แยก กันปักซ้อนสองหมุด

### ข้อมูลหมุดจากเซิร์ฟ

`MapPoi.server.lua` (เพลสหลักเท่านั้น) สแกนตอนบูต + ทุก 120 วิ → รายการ `{ id, cat, emoji, label, x, y, z }` ·
ไคลเอนต์ขอเมื่อเปิดแผนที่ (`Remotes.RequestMapPois` → `Remotes.MapPois`) แล้วจำไว้ · เหตุผล: StreamingEnabled ไคลเอนต์มองไม่เห็นของไกล
(บทเรียน QuestNav) · หมุดคงที่ (เมือง หมู่บ้าน แลนด์มาร์ก ถ้ำ) ไคลเอนต์อ่าน MapConfig เอง

กติกาล้วนอยู่ `MapPoiRules.lua` (ReplicatedStorage · เทสออฟไลน์ได้): ตารางหมวด อีโมจิตามชนิด (NpcKind ชนิดพาหนะ ชนิดสถานที่)
การรวมกลุ่มสายแร่ ซูมขั้นต่ำ และการกรอง
