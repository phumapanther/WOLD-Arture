# tiktok-bridge — TikTok LIVE → WOLD Arture

ไลก์เสกมอน ของขวัญหล่นหีบ กดซับได้บอสที่มีชื่อคนกดอยู่บนหัว คนดูพิมพ์คำสั่งบังคับตัวแอดมิน
และท็อป 3 ของไลฟ์สั่งฟ้าฝนกับเวลาได้

```
เบราว์เซอร์ TikTok LIVE
      ↓  tiktok-live-connector
tools/tiktok-bridge/bridge.js      ← โปรแกรมนี้ ถือคิวอีเวนต์ไว้
      ↓  HTTP GET /events?after=<id>   (เกมเป็นฝ่ายถาม ทุก 0.5 วิ)
src/ServerScriptService/TikTokLive.server.lua
      ↓  เรียกระบบที่มีอยู่แล้วในเกม
MobAccess · ChestAccess · StatusEffects · Vitals · WeatherAccess · DayNightAccess
```

## ทำไมเกมต้องเป็นฝ่ายถาม ไม่ใช่เราส่งเข้าไป

**เซิร์ฟเวอร์ Roblox รับ HTTP ขาเข้าไม่ได้** ไม่มี listener ไม่มีพอร์ต `HttpService` โทรออกได้ทางเดียว
ดีไซน์แบบ "POST เข้า Roblox" จึงสร้างไม่ได้เลย (โค้ดที่ยิงไปที่ `127.0.0.1:8080/tiktok-event` แล้วดูเหมือนทำงาน
คือกำลังคุยกับอย่างอื่นอยู่)

ตัวนี้จึงเก็บอีเวนต์ใส่คิวที่มี **เลขไอดีเรียงกัน** แล้วเกมถามว่า "มีอะไรหลังไอดีที่ฉันเห็นล่าสุดบ้าง"
ข้อดีที่ได้มาฟรีคือ **หลุดแล้วไม่หาย** — poll ตก เซิร์ฟแลค Studio รีสตาร์ท ก็แค่ถามด้วยไอดีเดิมอีกครั้ง

## เริ่มใช้

```bash
cd tools/tiktok-bridge
npm install                      # ครั้งแรกครั้งเดียว
node bridge.js --user PHUMAPANTHER
```
หรือดับเบิลคลิก `run.bat` (ติดตั้ง dependency ให้เองถ้ายังไม่มี)

ในเกม: `src/ReplicatedStorage/TikTokConfig.lua` → `Url` ต้องชี้มาที่นี่ (ดีฟอลต์ `http://127.0.0.1:8787`)
และต้องเปิด **Game Settings → Security → Allow HTTP Requests**

## เช็ค 4 ข้อก่อนกดไลฟ์

**TikTok Live Studio ไม่เกี่ยวกับตัวนี้เลย** สะพานไม่ได้อ่านจาก Live Studio และไม่ต้องมี OBS — มันคุยกับ API
สาธารณะของ TikTok ด้วย *ชื่อช่อง* เงื่อนไขเดียวคือ **บัญชีต้องอยู่ในสถานะ LIVE จริง** (ไลฟ์จากมือถือ
Live Studio หรือ OBS ก็ได้ ไม่ต่างกัน) เปิด Live Studio ค้างไว้แต่ยังไม่กด "ไปไลฟ์" = ยังต่อไม่ได้

| # | ต้องมี | ถ้าไม่มีจะเห็นอะไร |
|---|---|---|
| 1 | บัญชีกด **ไปไลฟ์** แล้วจริง และชื่อช่องใน `run.bat` ถูก | `❌ ต่อไลฟ์ไม่ได้: Failed to retrieve Room ID` วนทุก 15 วิ |
| 2 | **สะพานเปิดอยู่** (หน้าต่าง `run.bat` ค้างไว้ทั้งไลฟ์) | ในเกมเงียบ · `[TikTok] ต่อสะพานไม่ได้` ใน Output |
| 3 | **เกมรันอยู่** — Studio กด F5 หรือเข้าเกมที่ publish | `curl /health` ขึ้น `polls: 0` กับ `gameCursor: -1` |
| 4 | **มีแอดมินยืนอยู่ในเซิร์ฟ** (บัญชีใน `AdminRoster`) | เกมไม่ถามสะพานเลย (ตั้งใจ — ไม่มีแอดมินก็ไม่มีที่ให้ของโผล่) |

**เกมที่ publish แล้วยังใช้ไม่ได้ทันที** เซิร์ฟเวอร์ Roblox บนคลาวด์วิ่งมาที่ `127.0.0.1` ของเครื่องที่บ้านไม่ได้
ตอนนี้ที่ใช้ได้เลยคือ **ทดสอบใน Studio (F5)** · จะไลฟ์จากเกมจริงต้องต่อท่อก่อน ดูหัวข้อ
"เอาขึ้นเกมที่ publish จริง" ข้างล่าง

ดูว่าทั้งสายต่อกันติดจริงไหม: `curl http://127.0.0.1:8787/health` → ต้องได้ `connected: true` (ต่อไลฟ์ได้)
และ `polls` เพิ่มขึ้นเรื่อยๆ กับ `lastPollSecondsAgo` ต่ำๆ (เกมกำลังถามอยู่)

ยิงอีเวนต์เข้าไปเอง (**ใช้ node อย่าใช้ curl บน Git Bash** — คอนโซลวินโดวส์แปลงภาษาไทยเป็น cp874 ก่อนส่ง

### ธงอื่น

| ธง | ทำอะไร |
|---|---|
| `--user <ชื่อ>` | ช่อง TikTok ที่จะเกาะ (ไม่ต้องมี @) |
| `--port <n>` | พอร์ต (ดีฟอลต์ 8787) ต้องตรงกับ `TikTokConfig.Url` |
| `--key <คำ>` | ต้องส่ง `?key=` มาด้วยถึงจะตอบ ตั้งให้ตรงกับ `TikTokConfig.Key` |
| `--follow-boss` | ให้ "กดติดตาม" ได้บอสด้วย ไม่ใช่แค่ "กดซับ" (ดีฟอลต์ปิด — ติดตามมาถี่กว่ามาก) |
| `--dump` | พิมพ์ payload ดิบของอีเวนต์แต่ละชนิดครั้งแรกออกมา |
| `--likes <n>` | กี่ไลก์ต่อมอนหนึ่งตัว (ดีฟอลต์ 10) |

## endpoint

| | |
|---|---|
| `GET /events?after=<id>&max=<n>` | อีเวนต์หลังไอดีนั้น พร้อม `session`, `head`, `top` (ท็อป 3 ตอนนี้) |
| `GET /health` | สถานะ + `polls` / `gameCursor` / `lastPollSecondsAgo` — **ดูตรงนี้ว่าเกมดึงอยู่จริงไหม** |
| `POST /mock` | ยัดอีเวนต์เข้าคิวเอง (ทดสอบ) |

`gameCursor` คือของที่มีค่าที่สุดตอนหาสาเหตุ: **"ในเกมไม่มีอะไรเกิด" กับ "เกมไม่เคยถาม" มองจากข้างนอกเหมือนกันเป๊ะ**
แต่เป็นปลายสองด้านของสาย

## อีเวนต์ที่ส่งเข้าเกม

```jsonc
{ "kind": "mob",   "count": 2, "by": "somchai" }                          // ไลก์ครบ 10 × 2
{ "kind": "chest", "tier": "Chest_Gold", "label": "ใหญ่", "coins": 150 }   // ของขวัญ
{ "kind": "boss",  "by": "น้องเปิ้ล" }                                     // กดซับ
{ "kind": "cmd",   "text": "!มึน", "by": "มุก", "top": false }              // แชทที่ขึ้นต้นด้วย !
```

**ท็อป 3 คิดที่นี่ ไม่ได้อ่านจาก payload** — `isTopGifter` ของ connector ไม่มีในทุกเวอร์ชันและไม่ได้ใส่มาทุกอีเวนต์
และสิ่งที่ผู้ใช้ขอ ("ท็อป 3 ของไลฟ์") คือยอดสะสมทั้งเซสชัน ซึ่งมีแต่ตัวที่เฝ้าทั้งไลฟ์เท่านั้นที่รู้

## เอาขึ้นเกมที่ publish จริง

เซิร์ฟเวอร์จริงบน roblox.com **วิ่งมาที่ 127.0.0.1 ของเครื่องคุณไม่ได้** เลือกทางใดทางหนึ่ง

1. **ต่อท่อ (ง่ายกว่า)** เปิด `cloudflared tunnel --url http://localhost:8787` หรือ ngrok แล้วเอา URL สาธารณะ
   ไปใส่ `TikTokConfig.Url` · **ตั้ง `--key` ด้วย** ไม่งั้นใครก็ยิงอีเวนต์เข้าเกมคุณได้
2. **Open Cloud MessagingService** ตั้ง env `ROBLOX_API_KEY` (สิทธิ์ `universe-messaging-service:publish`)
   กับ `ROBLOX_UNIVERSE_ID` แล้วรันด้วย `--push` ตัวนี้จะ publish ไปที่ topic `TikTokLive`
   ฝั่งเกมต้องเพิ่ม `MessagingService:SubscribeAsync("TikTokLive", ...)` เข้า `TikTokLive.server.lua`
   (**ทางนี้ทดสอบใน Studio ไม่ได้** Open Cloud ส่งไม่ถึง Studio จึงไม่ใช้เป็นทางหลักในการพัฒนา)

## ข้อที่รู้แล้วว่าจะสะดุด

- **`new TikTokLiveConnection(user)` พังทันที** ใน v2.4.4 options object ตัวที่สองไม่ใช่ของที่ใส่ก็ได้ —
  constructor อ่าน `options.processInitialData` ตรงๆ จึง throw ก่อนจะได้ลองต่อเลย ต้องส่ง `{}` เป็นน้อยสุด
  (ไฟล์นี้ส่ง `processInitialData: false` กัน TikTok โยนประวัติย้อนหลังมาทั้งกอง และ
  `enableExtendedGiftInfo: true` ให้ค่าเพชรของของขวัญติดมากับอีเวนต์)
- **ตัวเซ็นคำขอเป็นของนอก** connector v2 เซ็นผ่าน `api.eulerstream.com` ทีเออร์ฟรีจำกัดต่อ IP — ไลฟ์ยาวๆ
  หรือรีสตาร์ทถี่ๆ อาจถูกปฏิเสธ ขอคีย์ฟรีที่ eulerstream.com แล้วรันด้วย `--sign-key <คีย์>`

- **ชื่ออีเวนต์ "กดซับ" ไม่ใช่ `subscribe`** ใน connector v2 คือ `subNotify` — `WebcastEvent.SUBSCRIBE` อ่านได้ `undefined`
  ซึ่งเป็นวิธีที่ฟีเจอร์บอสจะไม่ทำงานเลยตอนไลฟ์จริงทั้งที่เทสผ่านหมด ไฟล์นี้ลงทะเบียนทั้งสองชื่อไว้แล้ว
- **รูปร่าง payload ยืนยันได้จากไลฟ์จริงเท่านั้น** connector เปลี่ยนชื่อฟิลด์ระหว่างเวอร์ชันหลักและซ้อนบางตัวไว้ใต้
  `gift` → ถ้าของขวัญมาแต่ `coins` เป็น 0 ให้รันด้วย `--dump` ดู payload จริงแล้วเติมชื่อฟิลด์ใน `onGift`
- **ของขวัญแบบกดรัว (`giftType === 1`)** ยิงอีเวนต์ทุกเฟรมที่ยังกดอยู่ ต้องรอ `repeatEnd` ถึงจะนับ
  ไม่รอ = หีบโผล่ทุกเฟรม
- **สะพานรีสตาร์ทกลางไลฟ์** ไอดีเริ่มที่ 1 ใหม่ แต่เกมถือเลขเก่าที่สูงกว่าอยู่ → เคยค้างไม่รับอะไรอีกเลย
